## 新增 MinGW (Windows) 构建支持

将原本仅支持 Linux (unixgcc preset) 的 CMake 工程改为同时支持 Windows 下 MinGW-w64 编译。

### 改动文件
1. **CMakeLists.txt**
   - 新增跨平台数学库处理：`if(MINGW) set(HYD_MATH_LIB "")` 否则 `find_library(HYD_MATH_LIB NAMES m)`。
     原因：MinGW-w64 数学函数已在 C 运行时，无独立 libm；原 `target_link_libraries(... m)` 在 Windows 会报 `cannot find -lm`。
   - 所有原 `m)` 链接改为 `${HYD_MATH_LIB})`（含 HydroMotionLib / HydroSimLib 及多个测试目标）。
   - 新增 `HYD_THREAD_LIB`：`if(MINGW) winpthread` 否则空。
   - `main` 与 `benchmark_performance` 链接 `${HYD_THREAD_LIB}`：二者用到 nanosleep / clock_gettime（POSIX），
     在 MinGW-w64 实现于 winpthread，否则报 `undefined reference to nanosleep64 / clock_gettime64`。
2. **cmake/mingw_toolchain.cmake**（新建）：CMAKE_SYSTEM_NAME=Windows，编译器指向 `D:/mingw64/bin/gcc.exe`、`g++.exe`、`windres.exe`。
3. **CMakePresets.json**：新增 `mingw` configure preset（generator=MinGW Makefiles，PATH=D:/mingw64/bin）与 `mingw` build preset。

## 压力闭环控制仿真 harness + RBF vs PI 分析（brainstorming 任务）

新增 `tests/sim_pressure_control.c`：复用 `src/sim/PressureModel.c` 一阶分支（K=4.5 bar/rpm, τ=0.1s）作被控对象，
叠加齿轮泵齿落流量脉动（Z=13，相位取 `pump_phase_rev`）+ 传感器噪声；链路 PI/RBF-PI/RBF-PID → 泵转换器 → 模型。
已加入 CMake（mingw 预设）并构建运行成功，产出 `out/build/mingw/sim_output/*.csv` + `summary.csv`。

### 关键发现（用 MinGW 实测）
- **常规 PI（库内默认无前馈）很慢**：上升 6450ms、稳态误差 -10.2 bar（固定增益环路增益过小）。
- **公平基准 PI+FF**（注入稳态前馈 1.11 L/min）：上升 34ms、稳态 +0.07 bar —— 证明 PI 慢的根因是缺前馈，非结构。
- **RBF-PI/RBF-PID**：上升 201ms、稳态 ≈-0.2 bar。
- **RBF 真正优势在鲁棒/抗扰**：增益失配 K=5.4 时 PI+FF 漂到 +1.8 bar，RBF 保持 ≈0.0；8bar 负载阶跃恢复 RBF 5ms vs PI+FF 25ms。
- **电机位置前馈补偿脉动可行**：PI+FF/RBF-PI/RBF-PID 均实现 ~100% 纹波抑制（最优 K_ff≈-A≈-1.5 bar）。

### 工程结论
标称已知增益下 PI+FF 最优；存在不确定性（油温/磨损/漂移）时 RBF 自适应层更优。建议 PI+FF 作基线 + RBF 增强 + 电机位置前馈消纹波。

## 压力闭环控制工程实施方案（PI+FF+RBF 监督+电机位置脉动补偿）

用户认可了「PI+FF 基线 + RBF 监督增强 + 电机位置前馈消纹波」建议，补充硬件约束：**目标平台 STM32H7（480MHz，RAM 有限，单精度 FPU）**。
已完成 brainstorming 设计文档：`docs/superpowers/specs/2026-08-02-pressure-impl-design.md`。

### 关键工程约束（来自代码核查）
- `HYD_REAL` = `float`（单精度，`include/hyd_config.h:27,32`），STM32H7 单精度 FPU 原生支持 → **全程 float、禁 double**；代码库已用 `sinf/cosf/sqrtf` 后缀，须延续。
- 项目纯 C99、热路径禁动态分配（已有约束）。

### 设计要点（STM32 优化核心）
- 脉动补偿热路径改为**相位分箱查表（LUT, NBINS=26）**：每周期仅 `theta*NBINS` 取整索引 + 查表，O(1)、**热路径零 sinf/sqrtf**；LUT 仅在稳态期低频（每 256 周期）刷新时跑 26 次除法 + 可选 Goertzel。
- 相位源：优先编码器 `HYD_AxisRef.motorAngleRev`（新增 float 字段，默认 0 兼容），回退本控转速累加 `theta += Z·rpm·dt/60`。
- 增量分箱平均替代环形缓冲（省 RAM），状态 `HYD_PressureRippleCompState` ≈ 270 B。
- 关闭三级：FB 全局闸 + 段级 `rippleCompEnable` + HMI 参数；关闭即返回 0、零计算。
- FF 标定：`ffBase = targetPressure/systemGain`（仅段切换算一次，零每周期除法）+ 稳态期缓更新 `ffTrim` 学残差；`systemGain==0` 回退现有 `targetFlow`。
- 融合：新增 `HYD_PRESSURE_CONTROLLER_PI_RBF`，复用 `RBF_PID_Update` 出 adaptiveKp/Ki，但输出改用 PI 律并补回 `feedforwardFlow`（纯 RBF 模式丢 FF）。
