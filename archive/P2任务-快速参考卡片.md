## 🔧 技术要点

### 平台配置
```c
// 获取配置信息
HYD_ConfigInfo config = HYD_GetConfigInfo();
printf("Version: %s\n", config.versionString);
printf("Max Segments: %d\n", config.maxSegments);

// 自定义配置示例 (在hdy_config.h中)
#define HYD_MAX_SEGMENTS 8              // 低资源平台
#define HYD_MESSAGE_MAX 32              // 减少ROM
#define HYD_ENABLE_DIAGNOSTIC_MESSAGE 0 // 禁用诊断消息
```

### 配置分类

**1. 精度配置**
- HYD_REAL_PRECISION_FLOAT/DOUBLE
- HYD_REAL_EPSILON

**2. 数组大小限制**
- HYD_MAX_SEGMENTS (默认16)
- HYD_NAME_MAX (默认32)
- HYD_MESSAGE_MAX (默认64)
- HYD_DIAG_HISTORY_DEPTH (默认4)

**3. 功能开关**
- HYD_ENABLE_DIAGNOSTIC_MESSAGE
- HYD_ENABLE_DIAGNOSTIC_HISTORY
- HYD_ENABLE_PRESSURE_LOOP_TELEMETRY
- HYD_ENABLE_EXECUTION_REFERENCE

**4. 验证与保护**
- HYD_ENABLE_RECIPE_VALIDATION
- HYD_ENABLE_SENSOR_DATA_VALIDATION
- HYD_ENABLE_PROTECTION

**5. 性能优化**
- HYD_ENABLE_INLINE_FUNCTIONS
- HYD_ENABLE_FAST_MATH
