### 2. 可行性评审：B 有基础，但原描述还缺控制闭环

**可行部分**

- 库已具备泵排量、容积效率、最高转速配置，可换算名义泵流量。当前示例 50cc/rev、1700rpm、容积效率 0.95 对应约 80.75L/min。
- HYD_ActuationMapper_MapVelocity 使用当前位置求曲肘速度比，并按运动方向选择伸出/缩回有效面积；同一模块也有流量反算模板速度的接口。105 机构所需的运动学基础不必重建。
- 现有泵速/流量上限、压力限幅、软限位、位置停车包络与终速判定可以继续作为约束。动态流量目标只负责提高巡航速度，不能绕过这些约束。

**需要修正的部分**

1. 当前 HYD_MoveContinuousAbsolute 的 VELOCITY 是模板速度输入，没有流量目标；FLOWLIMITPERCENT 属于压力手柄的上限语义，不能复用成流量给定。若每个扫描周期改写 VELOCITY，HYD_AdvanceStatefulVelocity 会因目标改变而重新锚定过渡斜率，造成速度参考追不上动态上限。B 应有明确、可选的泵速/流量目标语义，并由库内状态维护其斜坡；不要改变现有直压轴和既有调用的含义。
2. 目前位置规划先产生模板速度，再映射成流量并受流量/泵速限制；输出保护器还可能继续削减流量。限幅后的泵命令没有完整回算到规划器的模板速度状态。因此“流量饱和后把规划速度钳到天花板”还不足以闭合状态链。新增路径必须让流量参考、可实现模板速度、输出限幅后的执行参考保持一致，并用当前位置和 105 运动学反算；压力、降额或保护削流后也要同步规划状态。
3. HYD_ActuationMapper_MaxTemplateVelocityOverRange 通过有限采样点估算区间最大速比（当前为 18 个采样位置），适合现有段速标尺用途，但不能不加裕量地当作所有内部极值的严格上界。B 的逐周期巡航换算应使用当前位置的有效速比；停车安全仍需覆盖控制周期内的位置变化，并保守处理高曲率区。
4. 位置制动上限和流量上限必须分别计算。建议模板坐标的最终速度命令满足 |v_cmd| ≤ min(v_flow(x), v_stop(x), v_process)，其中 v_flow(x) 由当前流量参考、方向对应油缸面积和 |R(x)| 反算，v_stop(x) 由剩余模板行程、经实测标定的减速度和响应延迟给出。流量参考不能取代位置停车包络。

### 3. 建议的最小设计方向

1. 在连续位置运动上增加明确的泵速/流量目标输入（名称和单位在实现计划中固定）；建议采用独立语义，例如目标泵速百分比或目标流量百分比。100% 仅表示请求使用已配置的泵能力，不表示无条件输出 1700rpm。有效请求仍须被泵最大转速、泵流量配置、运动段流量上限、压力限制和保护降额取最小值。旧调用保持原速度语义。
2. 在控制库内维护一个稳定的流量参考状态，以受控斜率爬升到请求值；斜率按现场驱动器/泵允许值标定。不要把每周期变化的速度天花板直接作为新过渡目标，也不要把 uiAcc=200ms 自动解释成安全的泵加速度：从 0 到 1700rpm 的等效给定斜率是 8500rpm/s，必须先核对驱动器跟随能力。
3. 每个控制周期用当前位置和带符号曲肘速比，把流量参考换成模板速度上限；与现有位置停车包络、工艺速度上限取最小，再经现有映射、泵转换和输出保护。保护器削减流量后，以限幅后的流量反算并同步规划参考，避免规划速度继续假定泵已实现未达到的速度。
4. 首期只做有斜率限制的流量斜坡和连续的位置制动，不新增全行程查表，也不宣称具备 jerk 限制。现有 IEC JERK 为 0 且非零值不支持。用 1ms 记录验证流量命令、模板速度、压力和位置变化没有阶跃或明显纹波放大；如线性斜坡仍有顿挫，再依据数据决定是否增加平滑段。
5. 只对显式启用流量参考的曲肘位置运动生效；直压轴、压力闭环、正常停止、急停和保护输出路径维持现有语义。低压护模/高压锁模继续由独立工艺阶段和压力/位置限制管理。

### 4. 关键风险与验收条件

- **泵速信号口径：** CSV 列名为 fbGetPumpRequest.PUMPSPEED，看起来是泵速请求值。若它确为请求而非驱动器实际转速反馈，只能证明控制器发出了多少转速请求，不能证明泵实际转速或驱动器是否到达额定转速。上机需同时记录泵速给定、驱动器实际 rpm、驱动器限幅/状态、压力和模板位置/速度。
- **响应延迟与过冲：** 本机拟合延迟约 20ms，而配置为 10ms。若额外 10ms 未补偿，在 600mm/s 下对应约 6mm 的延迟行程量级；这不是过冲的精确预测，但已足以说明当前参数不能支撑 <3mm 的保证。应按开、合模分别实测请求到运动响应的延迟；若只能配置一个值，先采用覆盖较慢方向的保守值，再用过冲数据调校。
- **压力与驱动器约束：** 达到名义流量不代表带载时仍有同等流量。压力限幅、伺服电机转矩/功率、驱动器加速能力、油液温度和模具阻力都会改变实得速度。100% 仅是请求上限，需检查限幅标志和实测 rpm。
- **平顺性：** 速度按几何比动态变化是目标效果，但快速变化的运动学比也会改变模板加速度。必须检查速度一阶差分、压力峰值和泵速跟随波动；现有测试不能替代实际油路、负载与模具保护测试。
- **上机验收：** 先以保守的流量比例和较长减速时间验证方向、限幅、停车与护模；逐级升高流量后，在同一模具、油温和压力条件下重复开/合模。至少验证速度曲线无明显顿挫、全过程未越过压力/泵速限值、快速合模≤1.13s、开模≤1.00s，且每次首次越过目标至停稳的最大位置过冲均<3mm。护模/高压段另行验收，不以快速合模时间覆盖。

### 5. 与行业做法的对照边界

从液压物理看，B 的控制层次是合理的：伺服泵转速决定名义可用流量，油缸面积和曲肘瞬时速度比决定模板速度，位置制动及低压护模负责终点和模具保护。这与伺服泵系统按流量/压力需求调节泵、锁模工艺区分快速运动与模具保护阶段的工程原理相符。此判断来自物理关系和本库控制边界，不等同于已核实某厂商控制器内部实现。它针对的是按整段最坏速比固定模板速度可能留下流量余量的问题。

但公开产品介绍通常只能证明厂商提供伺服泵系统、曲肘锁模或多段工艺功能，不能据此证明其控制器采用了本文的 q_ref → v_flow(x) 状态回算算法。本轮打开仓库所引的汇川官方方案页时只取得网页框架，详情接口未返回正文；仓库中的其他厂商网页/PDF引文也未能在本次评审中核验原文。因此不把 B 宣称为任何具体头部厂商已证实的实现。可靠的对照结论是“工程原理相符；具体厂商功能细节及算法是否同构尚无已核验证据”。若要作厂商级对标，需要取得可访问的官方操作手册/控制器手册，定位其开合模速度、低压护模和泵速给定章节后再引用。

### 6. 评审结论

B **有条件可行，建议进入实现设计**，但当前文档的“状态钳位即可保持 k≈1、停位精度不受影响、平顺性自然得到保证”说得过满。应改为：以库内流量状态为巡航给定，按当前位置运动学换算模板速度，同时保留并优先服从位置制动、压力限制和保护降额；限幅后同步规划状态。性能目标按本节修订为合模≤1.13s、开模≤1.00s、过冲<3mm；仿真和代码测试只能筛查方案，不构成上机性能承诺。

    巡航：在库内对流量参考做受控斜坡，再按当前位置的方向速度比与有效油缸面积反算模板速度上限；规划器不能只把每周期变化的速度天花板直接写成新速度目标。
    刹车和停位：位置停车包络独立计算并优先于流量上限，继续服从终速、压力和安全保护。参数 35 只在现有路径定义范围内补偿响应延迟；参数 36 是停稳判据，二者都不能单独证明过冲小于 3mm。
    平顺性：恒定流量可消除由模板速度标尺切段引起的泵流量跳变，但不自动保证模板加速度连续；曲肘速比变化、压力限幅和泵速响应仍须通过 1ms 轨迹验证。uiAcc=200ms 若用于 0→1700rpm 给定，等效斜率为 8500rpm/s，需先按驱动器能力限幅。
    不能只在 FB_HydAxis 里每周期刷新 VELOCITY：当前规划器在目标变化时会重锚过渡速率；MoveContinuousAbsolute 也没有可逐周期更新速度目标的 CONTINUOUSUPDATE 输入。
    接口需要明确区分流量目标和流量上限，并确保限幅后的流量与规划器参考状态同步；XML、plcdemo 和布局测试要同步更新。
