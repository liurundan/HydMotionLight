# 压力闭环控制算法仿真与分析报告

> 基于 `tests/sim_pressure_control.c`（MinGW 下编译运行），被控对象复用 `src/sim/PressureModel.c` 一阶分支。
> 运行：`cmake --build --preset mingw --target sim_pressure_control` → `out/build/mingw/sim_pressure_control`
> 数据：`out/build/mingw/sim_output/*.csv` + `summary.csv`

## 1. 仿真设置（用户给定）

| 参数 | 值 | 说明 |
|---|---|---|
| 系统增益 K | 4.5 bar/rpm | 电机转速→压力 |
| 滞后 τ | 100 ms | 一阶惯性时间常数 |
| 齿轮泵齿数 Z | 13 | 齿落流量脉动基频 = Z·rpm/60 |
| 脉动幅值 A | 1.5 bar | 约 1.5% 目标压力 |
| 传感器噪声 σ | 0.30 bar | 高斯白噪声 |
| 目标压力 | 100 bar | |
| 步长 / 时长 | 1 ms / 8 s | |

被控对象 = 一阶惯性 + 纯滞后（ring-buffer）+ 齿轮泵齿落流量脉动（相位取自 `pump_phase_rev`，即电机/泵实时位置）+ 传感器噪声。
控制器链路：`HYD_PressureController_Execute`（PI / RBF-PI / RBF-PID）→ `HYD_PumpConverter_Execute`（流量→转速）→ `PressureModel_Step`（转速→压力）→ 出口测量叠加脉动与噪声。

## 2. 核心结果

### 2.1 标称工况对比（K=4.5，无脉动前馈）

| 控制器 | 上升 (ms) | 调节 (ms) | 超调 % | 稳态误差 (bar) | 纹波 RMS (bar) | 纹波 p2p (bar) |
|---|---|---|---|---|---|---|
| PI | 6450 | 7999 | 0.00 | **-10.21** | 0.686 | 2.944 |
| **PI+FF**（稳态前馈） | **34** | **58** | 0.95 | +0.07 | 0.548 | 1.683 |
| RBF-PI | 201 | 263 | 0.84 | -0.19 | 0.634 | 1.862 |
| RBF-PID | 201 | 264 | 0.83 | -0.20 | **0.585** | 1.806 |

> 为公平隔离"自适应增益"贡献，新增 **PI+FF**：注入等效前馈流量 `target/(K·flow2speed)=1.11 L/min`。

## 3. RBF-PID / RBF-PI 是否真正优于常规 PI？

**结论：分两层回答。**

### (a) 对标称 PI（库内默认，无前馈）—— 碾压级优势
上升 201 ms vs 6450 ms（快 32 倍），稳态误差 -0.2 vs -10.2 bar，纹波更低。
常规 PI「慢且偏」的根因是**固定增益下环路增益过小且缺前馈**，并非 PI 结构本身不可用。

### (b) 对补了前馈的 PI（PI+FF，公平基准）—— 标称工况 RBF 并不更快
PI+FF 上升仅 34 ms，反而比 RBF 的 201 ms 更快。说明在**模型已知且恒定**时，PI+FF 性价比最高。

### (c) RBF 的真正优势 = 自适应带来的鲁棒性与抗扰性
- **增益不确定性**（K 由 4.5→5.4）：PI+FF 的前馈按错增益计算，稳态误差漂移到 **+1.8 bar**；RBF 自适应保持 **≈0.0 bar**。
- **抗扰**：8 bar 阶跃后 RBF 恢复 **5 ms**，PI+FF 需 **25 ms**。
- **纹波**：RBF-PID 纹波 RMS 最低（0.585 bar）。

## 4. 关于"用电机实时位置补偿低压纹波"

**可行，且效果显著。** 齿轮泵压力脉动频率 `f = Z·rpm/60`，与转速正相关、随转速降低周期变长——与现场「低速时纹波周期与转速相关」的现象一致。
脉动相位 `φ = 2π·Z·pump_phase_rev` 可直接由泵位置推出，注入反向同频脉动即可抵消：
PI+FF / RBF-PI / RBF-PID 均实现 **~100% 纹波抑制**，最优前馈增益 `K_ff ≈ -A ≈ -1.5 bar`。
（常规 PI 因压力未稳定在目标附近，脉动叠加在缓变基线上，抑制率仅 32.6%。）

## 5. 工程建议

1. **基线用 PI+FF**：在增益已知且恒定的工况，PI+FF 速度最优、实现简单。
2. **自适应层用 RBF**：当存在油温/黏度变化、泵磨损、阀口漂移等**模型不确定性**时，叠加 RBF-PI/RBF-PID 自适应增益补偿，避免固定前馈因参数漂移而失效。
3. **必做电机位置前馈**：对齿轮泵流量脉动，用 `pump_phase_rev` 在线标定 K_ff（建议随齿数/排量自整定），可消除 ~100% 出口压力纹波。
4. **前馈增益在线学习**：K_ff 随工况（油温、泄漏）缓变，可用最小二乘/梯度法在线更新，避免出厂定值随老化失准。

## 6. 局限与下一步

- 当前被控对象为一阶近似；后续可接入 `PressureModel` 物理分支（容积弹性、泄漏、溢流阀）验证非线性与饱和下的结论。
- 脉动模型为单一正弦齿落；真实齿轮泵含多阶谐波，前馈可扩展为多谐波查表。
- 噪声/扰动为加性高斯；可加入相关性、间歇性负载以更贴近产线。
- 建议把 `sim_pressure_control` 接入 ctest，作为算法回归基准。
