PI+FF 基线 + RBF 自适应增强层 + 电机位置前馈在线标定（齿轮泵脉动抵消）。当前讨论稿，数据待回填。

① 总体架构（建议）

三层解耦：① PI+FF 基线 负责确定性跟踪；② RBF 自适应层 在扰动/模型失配时整定增益与系统增益；③ 脉动补偿器 用泵角度标定齿落相位、抵消出口纹波。三者可独立开关。

② 脉动信号提取流水线（需求③的数据分析模块）

相位来源两方案：A 用编码器真实角度（最准，需新字段喂入）；B 用本控指令转速做相位累加 θ += Z·rpm·dt/60（自包含、无需新字段，假设无滑差）。见需求③澄清。

③ 三类核心动作的控制器映射（需求②）

动作主要控制模式建议基线 → 增强层脉动补偿关键诉求
合模 / 开模位置→保压（吨位）PI+FF 定吨位；RBF 适应模具差异/油温低速合模段开启确定性、无过冲、锁模力稳
射胶（注射）速度段→保压段（V/P 切换）PI+FF 保压；RBF 适应熔体压缩性/粘度保压段开启V/P 平稳切换、重量重复精度
顶针位置为主 + 压力上限PI+FF；RBF 轻量通常关闭低力、避免顶伤、快速回退

每段的 pressureController 字段已支持 PI / RBF_PI / RBF_PID 选择；融合方案建议新增“PI+FF 基线 + RBF 监督整定”模式，由 RBF 在线修正 PI 增益与 systemGain，而非完全替换 PI。

④ FF 稳态保持流量标定（需求①）

稳态关系（一阶模型）：P* = K_bar_per_rpm · flow* · flow2speed ⇒ 理想保持流量 flow* = targetPressure / (K · flow2speed)。

当前 feedforwardFlow = segment->targetFlow 为配方人工设定，常与实际 flow* 偏差 → 产生稳态误差，需积分缓慢补偿。建议：

方案做法优点 / 风险
物理推导用 segment->systemGain 计算 flow*快；但 systemGain 需按机台/油温标定
在线标定稳态期测实际保持流量，缓更新 FF自适应；需“稳态判定”闸门防抖
两者结合（推荐）物理推导作初值，在线标定作微调兼顾收敛速度与自适应
