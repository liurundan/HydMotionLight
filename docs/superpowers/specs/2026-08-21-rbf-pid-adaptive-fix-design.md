## 0. 目标与范围

**一句话目标**：把 RBF-PID 从"带无效神经网络装饰的限幅增量 PID"改成一个 Jacobian 符号正确、增益窗口足够宽、跨周期保留学习、有可信度门控的**真自适应**压力闭环控制器；默认段仍走 PI/PID，RBF-PID 保持按段 `HYD_PRESSURE_CONTROLLER_RBF_PID` 显式选择（现状已是非默认，本设计不改变默认）。

**两条硬约束（贯穿全文，每条改动都须满足）**：
- **A. 逻辑自洽**：每个算法改动必须逻辑正确、互不冲突、可工程实施；实施时逐条核对与相邻改动无矛盾。
- **B. 一阶模型达标**：最基础的一阶惯性模型（`PressureModel` 的 `PRESSURE_MODEL_TYPE_FIRST_ORDER`）实验数据也要符合预期，超调量与稳定性达到工业水平。

**修复范围（全部一起修）**：
- 核心缺陷 2.1–2.5：增益窗口放宽、Jacobian 硬钳位非负、可信度门控、跨周期保留网络、增量式增益变动平滑。
- 工程缺陷 2.6/2.7：魔法系数入 `hyd_config.h`、稳态判据随量程缩放、状态机/前馈过渡段反向作用抑制。
- 实现级 4.x：动量时间基准统一、种子接入网络初始化、PI 路径避免跑全套 RBF、Jacobian 偏导语义修正、死区跳变、`soft_flow_cap` 在 K=0 的退化。

**验收定义（"有效"的量化判据）**：在 `PressureModel.c` 上跑三段物理基准（多级保压降压 / V/P 切换 / 20bar 低压顶针）+ 一阶模型阶跃场景，修后 RBF-PID 的 ITAE / 超调 / 稳态纹路 RMS / 切换峰值**不劣于**定增益 PI+前馈；并因跨周期保留网络在至少一段（预期保压降压段）上**优于**冷启动定增益。同时新增 `rbf_pid.c` 行为单元测试。

## 1. 窗口宽度 / 被控对象 / 两种模型的一致性（关键解耦逻辑）

**暴露的矛盾**：把 `KP` 窗口无差别放宽到 ≥10× 以覆盖物理模型的 `beta` 数量级增益变化，会在一阶模型（增益恒定、温和、强稳定）上把增益推高导致超调 —— 与约束 B 冲突。

**解耦设计（使两约束正交）**：
1. **窗口放宽 = 能力上限，非"一定用满"**。窗口给到覆盖数量级（KP ≥10×，KI/KD 相应），但增益实际走向由**门控后的 Jacobian 梯度**决定：温和对象（Jacobian 小、误差小）时增益停在低位；刚硬对象（Jacobian 大）时才爬升。前提是 Jacobian 量纲/符号正确（见 §2）。
2. **默认窗口保守 + 按段可覆盖**：`hyd_config.h` 全局默认放宽到覆盖数量级但**上限带阻尼**（上限取近临界阻尼估计，而非振荡边界）；每段用已存在的 `segment->pressureRbfConfig` 收窄/放宽，无需改 struct。
3. **超调主闸门放在增益/输出层**（见 §3.1 增益 slew-rate + 输出软限幅），不靠窗口约束超调。

**结论**：窗口宽是"允许到达的范围"，门控与 slew 是"何时、以多快到达"，二者正交。→ 一阶模型用保守段配置验证稳定性；物理模型用宽窗验证自适应覆盖。

## 2. Jacobian 符号保护 + 可信度门控（自适应回路正确性核心）

### 2.1 Jacobian 硬钳位为非负（评审 2.2）
- 现状 `clamp(Jacobian, -5, 50)` 允许负号 → 增益反向整定，KI 项 `eta_i·error²·Jacobian` 被负 Jacobian 单调抽空。
- 改为 `clamp(Jacobian, J_min, J_max)`，`J_min = HYD_THRESH_RBF_JACOBIAN_MIN`（0 或小正数，避免除零/停滞），`J_max = HYD_THRESH_RBF_JACOBIAN_MAX`。物理硬约束 `∂P/∂Q ≥ 0`。
- **自洽检查**：钳位后 `error²≥0` 且 `Jacobian≥0` → KI 不会被抽空；KP/KD 方向由 `de/dde` 决定，符号语义清晰。
- 常量入 `hyd_config.h`。

### 2.2 预测误差可信度门控（评审 2.3，采用误差门控，不加 PE）
- 计算网络预测误差 `error_rbf = y_n - y_hat_n`（量已存在，未用于门控）。
- 维护其低通滤波幅度 `|error_rbf|_filt`；超过 `HYD_THRESH_RBF_IDENT_TRUST` 时判"辨识不可信" → **冻结增益更新**（`step_adaptive_gains` 直接 return，仍用当前增益控制），但**网络参数 w/c/b 继续学习**以追上对象。
- **自洽检查**：门控冻结的是"用 Jacobian 调增益"，非"控制输出"；控制器始终有输出（用最近可信增益），不停摆。与 §4.1 跨周期保留协同：门控期间网络继续收敛，可信后解冻调增益。

### 2.3 不加 PE 的兜底逻辑（已决策不加 PE）
- 保压稳态无持续激励时，误差门控天然兜底：网络预测若与实际脱节，`|error_rbf|` 升高 → 冻结增益 → 退化为定增益（安全）；若预测仍准（对象未变），继续微调无害。故不加 PE 可接受。

### 2.4 偏导语义修正（评审 4.1）
- 现 Jacobian 仅对 `x[0]=du_prev` 求偏导，概念是 `∂y/∂(du)` 而非对象稳态增益 `∂P/∂Q`。修正为对流量域输入求偏导并乘正确的 `pressure_scale/flow_scale`，与 §2.1 非负钳位共同保证量纲与符号正确。

## 3. 增量式增益平滑、过渡段、判据缩放（评审 2.5 / 2.6 / 2.7）

### 3.1 增益 slew-rate 限幅（评审 2.5，超调主闸门）
- 问题：`du = KP·Δe + KI·e + KD·Δ²e` 要求 KP/KI/KD 相邻拍近似恒定；逐拍变动使 `KI·e` 等效积分基准漂移 → 输出脉动 → 保压纹路。
- 修法：对增益本身做**变化率限幅**，每拍 `|ΔKP/ΔKI/ΔKD|` ≤ `HYD_THRESH_RBF_GAIN_SLEW_RATIO·(max−min)`。增益仍能自适应爬升到宽窗，但单拍不跳变，增量式前提近似成立，输出无脉动。
- **自洽检查**：与 §1 正交（窗口=范围，slew=速度），与 §2.2 门控正交（门控决定"是否调"，slew 决定"调多快"）。

### 3.2 状态机/前馈过渡段反向作用抑制（评审 2.7）
- 泄压（RELIEF）态 `f_uff = -0.15·dd_press` 可能反向加流量，与泄压意图冲突：泄压态**禁用加速度前馈**，或仅当前馈方向与控制误差方向一致时才施加（符号一致性门控）。
- V/P 切换瞬间 `control_state` 快速跳变致学习率缩放抖动：对 `control_state` 引起的 `learning_scale` 变化加去抖，切换瞬间**复用 §2.2 冻结机制**冻结增益整定，切换后重新使能。
- **自洽检查**：切换瞬间本应"稳"，冻结整定 + 前馈符号门控 → 方向不与意图冲突。

### 3.3 稳态判据随量程缩放（评审 2.6）
- 现 `e_steady=5.0 bar`、`delta_u_steady=2.0` 写死；对 20bar 量程过粗（25%）。
- 改为相对量程：`e_steady = HYD_THRESH_RBF_STEADY_ERROR_RATIO · pressure_scale`（`pressure_scale` 已是每段量程标量）；`delta_u_steady` 同样相对化。`control_state` 分档阈值（`0.02`、`-0.01·setpoint`）、学习率缩放 `{0.10,0.25,0.50}` 全部提取为 `hyd_config.h` 命名常量（CLAUDE.md §14B）。
- **自洽检查**：一阶（250bar）与顶针（20bar）用同一 ratio → 物理意义一致，两模型都合理。

### 3.4 前馈/魔法系数入配置（评审 2.6）
- `RBF_PID_ACCEL_FF_GAIN`、`RBF_PID_DYNAMIC_FF_GAIN`、软死区、软限幅比例等迁入 `hyd_config.h` §14B，附物理量纲注释。

## 4. Reset 生命周期重构、种子、PI 路径、实现级修复（评审 2.4 / 4.x）

### 4.1 跨周期保留网络（评审 2.4，采用跨周期保留）
- 现状 `needsAdaptiveReset` 在 `targetPressure` 下降时触发 `RBF_PID_Reset()`（全 memset + 重铺），学习反复清零。
- **重置判据收窄**为两类：(1) 首次初始化 `!rbfInitialized`；(2) 归一化基准变更（`pressure_scale`/量程/传感器配置变化，使已学 c/b 失配）。
- 降压（目标下降）**不再重置网络**，改为 bumpless 种子：保留 `w/c/b`，仅对齐 `u_prev/Output/e_prev/y_prev/last_ref` 到新目标与当前反馈，避免输出跳变。
- **API 拆分**：
  - `RBF_PID_ReseedRuntime()` —— 只对齐运行时状态、保留网络；降压/换段常规路径走此。
  - `RBF_PID_Reset()` —— 保留原行为，仅在基准变更时调用。
- **自洽检查**：与 §2.2 门控协同 —— 换段后若网络对新工况暂不可信，门控冻结增益整定、网络继续学，不再每段冷启动。

### 4.2 种子接入网络初始化（评审 4.7）
- `network_seed` 现"仅存储未接入"。在 `rbf_pid_init_network()` 用 seed 驱动确定性 PRNG（xorshift 风格，可参考 `PressureModel.c`）为 c/w/b 加确定性小扰动，保证复现；seed=0 退回当前确定性铺开值（不破现有测试）。

### 4.3 PI 路径避免跑全套 RBF（评审 4.3）
- 现状 PI 模式仍跑整套 6×3 RBF（只是不用 KD），特判散布 6+ 处。
- 修法：PI 模式**短路 RBF 辨识与 Jacobian 计算**，增益走固定 PI 逻辑，把散落特判收敛到单一分支入口。**不改 PI 数值输出行为**，仅去无效计算 + 降维护面。
- **自洽检查（强制前提）**：短路前先跑现有测试建基线；短路后 `test_pressure_controller`、`rbf_pid_test`、`test_rbf_pid_hil` 必须全绿，确认无测试依赖"跑 RBF 但不用"的副作用。

### 4.4 soft_cap 退化 / 动量基准 / 死区跳变（评审 4.5 / 4.6 / 4.2）
- **soft_flow_cap（4.5）**：K=0（未配 systemGain）时软限退化为硬限，保护失效。改为 K=0 时用基于 `pressure_scale/flow_scale` 的物理默认软限。
- **动量基准（4.6）**：权重用 `w−w_1`、中心/宽度用 `ci_1−ci_2`，时间基准不一致。统一为标准 RBF 动量 `θ_1−θ_2`（上一拍−上上拍）三者一致。
- **死区跳变（4.2）**：±0.0005 硬死区致 `Δe` 台阶。改为软死区/斜坡连续过渡，消除高 `beta/V` 下可见台阶。

## 5. 验证方案

### 5.1 `rbf_pid.c` 行为单元测试（新增 `tests/test_rbf_pid_adaptive.c`，注册 CMake + ctest）
- Jacobian 非负：构造使旧代码产负 Jacobian 的输入，断言修后 `Jacobian ≥ J_min`。
- 增益不被抽空：稳态误差存在时 KI 不单调撞下限。
- 增益 slew-rate：单拍 `|ΔKP/ΔKI/ΔKD|` ≤ 窗口比例限。
- 门控冻结：注入高预测误差 → 增益冻结、网络参数仍更新、输出不停摆。
- 跨周期保留：降压后 `w/c/b` 未清零（Reseed 路径）；基准变更时重置（Reset 路径）。
- 种子复现：同 seed 两次 init → 参数逐位相等；seed=0 → 退回确定性铺开值。
- 判据缩放：20bar 与 250bar 量程稳态判据相对量程一致。

### 5.2 仿真基准台（新增 `tests/test_rbf_pid_benchmark.c`，链接 `HydroMotionLib + HydroSimLib`）
对象 `PressureModel.c`；对照 定增益 PI+前馈 vs 修后 RBF-PID。
- **场景 0（一阶模型，约束 B）**：`FIRST_ORDER`，阶跃 0→100bar 与 100→50bar 降压。工业门限：超调 ≤ 阈值（建议 ≤5%，实测标定后写死）、稳态误差 ≤ 量程小比例、无持续振荡（纹路 RMS 低于阈值）、稳定时间达标。RBF 在温和对象上不得劣于 PI。
- **场景 1**：250→150→80bar 多级保压降压（物理模型）。指标：ITAE、超调、纹路 RMS。预期 RBF 因跨周期保留不劣于/优于 PI。
- **场景 2**：V/P 切换冲击。指标：切换瞬态峰值。验证 §3.2 过渡段冻结有效。
- **场景 3**：20bar 低压顶针。指标：超调。验证 §3.3 判据缩放后低压不过冲。
- 每场景输出指标数值 + 断言门限（门限为测试常量，实测标定并留安全裕度）。

### 5.3 回归保护
- 实施前 `ctest` 全绿建基线；每个改动后重跑 `rbf_pid_test`、`test_pressure_controller`、`test_rbf_pid_hil`、`test_pressure_model` 保持全绿。
- 嵌入式生产构建 `./scripts/deploy_embedded_prod.sh` 保持可编译（RBF 属核心库，不依赖 sim）。

### 5.4 待实施时标定的细节（非占位符，方法已定，数值依实测）
- 工业门限具体数值（超调%、纹路 RMS、稳定时间、ITAE 上界）在对象跑出基线后标定，plan 阶段填实测值并留裕度。

## 7. 风险与注意事项

- **接口稳定性**：`RBF_PID_Handle` struct 字段偏移不随意改动（注释注明历史约束）；新增运行时状态字段追加到末尾。
- **PI 短路**：必须以现有测试全绿为硬前提，避免隐性行为回归。
- **门限标定**：工业门限依赖实测，不得凭空写死；标定方法在本设计固定，数值在 plan 阶段填入。
- **配置迁移**：所有新阈值集中 `hyd_config.h` §14B，附物理量纲注释；新 `src/*.c`（若拆分）需重跑 `cmake --preset unixgcc`。
- **默认不变**：RBF-PID 仍非默认，关键工况（保压/顶针）由段配置显式选择；本设计不改变默认控制器选择逻辑。
