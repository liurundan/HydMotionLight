# RBF 卸压自适应冻结核心设计

## 目标

在嵌入式 1 ms 压力控制循环中，阻止反向卸压、RBF 输入外推和低压低信噪比样本更新共享 RBF 网络及 PID 自整定参数，同时保持当前控制输出链路、前馈、速度阻尼、限幅和压力历史连续。

## 范围

- 修改 `RBF_PID_Handle` 的运行时自适应门控状态。
- 在 `RBF_PID_Update()` 内统一约束网络参数更新和 KP/KI/KD 更新。
- 保留 `RBF_PID_Update()` 公共 API，不引入动态内存、第二网络或新的外层状态机。
- 不以目标压力下降或 `reliefActive` 作为学习冻结判据。
- 增加反向卸压、多段目标下降、低压和恢复预热回归测试。

## 门控语义

令 `freeze_learning` 在任一条件满足时为真：

1. 上一拍已施加输出或当前候选输出为反向流量；
2. RBF 输入向量超出允许覆盖域；
3. 实际压力低于配置量程的低压阈值。

压力下降方向只用于确认反向卸压，不能单独触发冻结。目标压力变化只参与正常跟踪，不能触发冻结。

## 执行顺序

RBF 前向计算和控制输出继续执行。冻结只旁路：

- 网络权值、中心、宽度更新；
- KP、KI、KD 在线整定；
- 冻结期间的 Jacobian 连续负号计数更新。

`jac_neg_count` 在冻结期间保持；恢复阶段先经过短暂有效样本预热，再恢复增益整定。卸压路径不调用 `RBF_PID_SoftReset()`。

## 恢复

输出回到非反向区、压力下降方向解除、输入回到覆盖域且低压条件解除后，先恢复网络学习 1～2 拍，再恢复 PID 增益整定。控制输出始终保持连续运行。

## 验证

回归测试必须证明：反向卸压不改变网络和增益；目标下降但正向跟踪不冻结；低压和外推冻结；冻结期间计数保持；恢复预热不产生输出跳变。
