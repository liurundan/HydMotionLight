# 液压运动控制时间参数与平滑轨迹设计

## 1. 背景与目标

当前 IEC `FB_HydAxis` 在 PLC 层把 `uiAcc/uiDec` 按最大速度反算为 `mm/s²`，并把压力过渡时间转换为 `bar/s`。液压库内部的运动规划器和压力 ramp 控制器因此接收的是派生速率，导致接口语义分散：连续速度交接、短距离准确到位、停止和压力目标在线更新都可能使用不一致的换算基准。

本设计统一将 IEC 输入参数定义为时间，由液压库内部完成归一化和物理量换算。目标是：

- 加减速输入表示当前速度到目标速度/终点速度的过渡时间；
- 压力输入表示当前内部压力设定到新目标压力的过渡时间；
- 速度命令在控制周期之间连续，位置终点减速不产生速度突变；
- 压力设定值平滑变化，目标压力在线修改时不跳变；
- 复杂计算集中在液压库，`FB_HydAxis` 保持输入映射和状态管理职责；
- 已经无法准确到位时保持原运动方向平滑减速，允许越程，不反向修正、不急停、不置运动故障。

本次接受接口语义的破坏性变更。字段名称保持 PLC 工程绑定兼容，但字段单位和文档语义统一改为毫秒。

## 1.1 敏捷实施与嵌入式约束

以可运行、可测量的最小增量交付，不先建立通用轨迹框架或扩大到 jerk/S 曲线。按以下切片实现，每个切片都能单独构建和验证：

1. 先完成接口单位注释、时间归一化和核心参数测试；
2. 再完成运动规划的连续速度过渡、短行程降速和普通停止；
3. 然后完成压力设定值定时过渡及连续更新；
4. 最后精简 `FB_HydAxis` 并运行端到端回归。

每个切片先覆盖可观察的行为，再实现满足测试的最小逻辑。优先复用现有 `HYD_MotionPlannerState`、`HYD_RampController` 和停止状态，不增加动态内存、轨迹采样缓冲区、通用调度器或重复保存的状态。只增加实现该过渡必需的定长状态字段；完成一个切片后检查结构体大小和静态内存变化。嵌入式路径保持固定周期、确定性执行和有界计算量。

## 2. 参数契约

### 2.1 运动参数

以下参数统一表示时间，单位为 `ms`：

- `HYD_MOVEABSOLUTE.ACCELERATION`
- `HYD_MOVEABSOLUTE.DECELERATION`
- `HYD_MOVECONTINUOUSABSOLUTE.ACCELERATION`
- `HYD_MOVECONTINUOUSABSOLUTE.DECELERATION`
- `HYD_MOVEVELOCITY.ACCELERATION`
- `HYD_MOVEVELOCITY.DECELERATION`
- `HYD_STOP.DECELERATION`
- `FB_HydAxis.uiAcc`
- `FB_HydAxis.uiDec`

运动时间归一化规则：

- `0 ms` 或小于 `100 ms` 的值按 `100 ms` 处理；
- 大于等于 `100 ms` 的值按输入值处理；
- 负数、非有限数或无法转换的值拒绝命令并报告 `COMMAND_NOT_ALLOWED`；
- 运动时间的语义是当前规划速度到目标速度、终点速度或零速的过渡时间，不是按固定参考速度反算的恒定加速度。

`JERK` 和 `uiJerk` 保留为兼容针脚。本阶段不实现 jerk/S 曲线，非零 jerk 仍按现有接口规则处理；`FB_HydAxis` 不再对其做单位换算。

### 2.2 压力参数

以下参数统一表示压力目标过渡时间，单位为 `ms`：

- `HYD_PRESSUREHANDLE.PRESSURERAMPRATE`
- `HYD_AXISMOTION.PRESSURERAMPRATE`
- `FB_HydAxis.uiPressureAccTime`

压力时间归一化规则：

- `0 ms` 使用默认 `20 ms`；
- 正值按原值执行，包括小于 `20 ms` 的正值；
- 负数、非有限数或无法转换的值拒绝命令并报告 `COMMAND_NOT_ALLOWED`。

`bar/s` 只允许作为库内部每周期计算的瞬时量，不出现在 IEC 接口和 `FB_HydAxis` 计算逻辑中。

## 3. 模块边界

### 3.1 IEC 层职责

`FB_HydAxis` 只负责：

- 输入边沿检测和模式状态机；
- 将工艺输入映射到对应 IEC FB；
- 传递毫秒时间参数；
- 汇总 Busy/Done/报警/到位状态。

删除或移除以下 IEC 层物理换算职责：

- `CalcPresRampRate` 方法；
- `rPressureRampRate` 和 `rPresLastCycle` 状态；
- `rAcc/rDec/rStopDec` 从时间到 `mm/s²` 的换算；
- 压力目标差值到 `bar/s` 的计算。

PLC 扫描周期固定为 `1 ms`。周期值应集中定义为常量，不能在 ST 中散落魔数。

### 3.2 液压库入口职责

`motion_interface.c` 负责将 IEC 的毫秒字段统一归一化为内部秒制时间，并构造运动段和在线更新请求。`HYD_AXISMOTION`、直接运动 FB、压力 FB、停止 FB 必须使用相同的归一化策略。

内部段结构和在线更新请求应使用明确的时间字段，例如：

- `accelerationTime`；
- `decelerationTime`；
- `pressureRampTime`。

内部不得继续把 IEC 输入直接解释成 `maxAcceleration` 或 `pressureRampRate`。如为保持嵌入式 ABI 或历史结构布局需要暂留旧字段，必须在库入口完成一次明确转换，并禁止调用方重复换算。

## 4. 运动规划设计

### 4.1 时间状态

`HYD_MotionPlannerState` 增加或等价维护以下运行状态：

- 过渡起始速度；
- 过渡目标速度；
- 过渡已用时间；
- 过渡总时间；
- 当前阶段（加速、匀速、减速、终点收敛）。

阶段开始时建立一次过渡，不在每个周期用新的瞬时速度重新计算斜率。目标速度或时间在线更新时，从当前已输出规划速度重新建立受限过渡，以保证速度输出连续。

等效加速度仅在库内使用：

```text
acceleration = abs(targetVelocity - startVelocity) / transitionTime
```

### 4.2 位置段与准确到位

位置规划继续使用剩余距离制动包络，但制动条件改用时间语义。对于当前速度、终点速度和归一化减速时间，库内估算需要的制动距离，并保留一个 `1 ms` 控制周期响应余量。

若剩余距离不足以容纳当前速度的减速时间，规划器提前降低内部可行速度上限，再以连续过渡跟随。PLC 原始 `VELOCITY` 设定不被改写。

对于短行程，优先降低可达峰值速度，而不是通过速度跳变或急停强行满足位置。位置完成仍需同时考虑：

- 位置误差在位置容差内；
- 规划速度和实际速度在稳定速度容差内；
- 配置的稳定窗口（如有）。

### 4.3 连续绝对运动

`HYD_MOVECONTINUOUSABSOLUTE` 的 approach 和 sustain 阶段共享时间状态和速度连续性约束。到达位置切换点时，使用同一控制周期的连续速度输出切换到终点速度过渡，不能直接替换速度值。

`ENDVELOCITY` 可按当前方向平滑过渡。若目标终点速度在剩余距离内不可达，内部降低 crossing velocity；不能通过提高 crossing velocity 来补偿制动距离不足。液压轴没有可随意使用的反向制动能力，方向切换必须由显式业务命令控制。

### 4.4 不可行到位与越程

若外部负载、压力/流量限幅、反馈迟滞或响应延迟使准确到位已不可实现：

1. 保持原运动方向；
2. 按归一化减速时间平滑减速至停止；
3. 允许越过目标位置；
4. 不自动反向修正；
5. 不触发急停；
6. 不置运动故障或 `bAlarm`；
7. 记录 warning 级“位置未到位”结果。

为避免把命令结束误认为位置到达：

- `HYD_MOVEABSOLUTE` 增加 `POSITIONREACHED` 输出；
- `FB_HydAxis` 增加 `bPositionReached` 输出；
- 正常停稳即结束命令，故 `DONE=TRUE`、`BUSY=FALSE`、`ERROR=FALSE`；`POSITIONREACHED` 单独表示停稳位置是否进入容差。越程停稳时 `POSITIONREACHED=FALSE` 并记录 warning，避免将命令未结束和位置未到位混为一谈；
- `HYD_MOVECONTINUOUSABSOLUTE.POSITIONREACHED` 继续表示通过位置切换点，不改变其持续运动语义。

位置段结束时必须按实际停稳位置判断是否在容差内，不能仅根据单方向“已越过目标”的条件把越程判为到位。

## 5. 停止与急停

### 5.1 普通停止

`HYD_STOP.DECELERATION` 表示普通停止减速时间，按运动时间规则归一化到至少 `100 ms`。停止请求捕获停止瞬间的有效反馈速度；反馈无效时回退到当前规划速度。停止轨迹按当前方向连续减速到零，不能继承旧段残留的加速度或减速度。

### 5.2 急停

急停不复用普通 `HYD_STOP.DECELERATION`。`FB_HydAxis` 不再用 `99999.0` 模拟急停时间，而是调用独立的安全停止路径。急停可采用现有安全策略，优先保证安全输出和停机确定性，允许与普通运动的平滑时间语义不同。

## 6. 压力 ramp 设计

库内压力 ramp 状态至少保存：

- 当前内部压力设定值；
- 当前目标压力；
- 本次过渡起点；
- 过渡已用时间；
- 过渡总时间；
- 上次目标和时间参数。

首次进入压力段时，内部设定值从有效压力反馈初始化。目标压力或压力时间改变时：

1. 读取当前已生成的内部设定值；
2. 以该值作为新过渡起点；
3. 更新目标压力和过渡时间；
4. 本周期不跳变，下一周期开始新过渡。

压力控制器接收 ramp 后的目标设定，不直接接收原始目标压力。到达目标时钳位到目标值，消除浮点残差。

`INPRESSURE` 必须同时满足：

- 压力 ramp 已完成；
- 实际压力进入目标容差；
- 配置的稳定条件满足。

实际压力仍受泵、阀、负载和压力控制器动态影响，时间参数只约束内部设定轨迹。

## 7. 校验与诊断

- 运动时间和压力时间在所有入口统一校验，避免 IEC FB、配方和在线更新出现不同默认值；
- 非法输入报告 `COMMAND_NOT_ALLOWED`；
- 位置越程未到位使用 warning 级结果，不置 `ERROR`、不触发保护停机；
- 急停和普通停止分别保留独立的诊断与状态路径；
- 速度连续性和压力设定连续性属于规划器/ramp 的内部不变量，应通过测试直接检查每周期差值和阶段交接。

## 8. 验证计划

新增或迁移以下测试：

1. 运动时间 `0/99/100 ms` 归一化，压力时间 `0/5/20 ms` 行为；
2. 负数和非有限时间输入拒绝；
3. 不同初速度、目标速度和在线更新下速度每周期无跳变；
4. 短距离位置段自动降低峰值速度并在可行时准确到位；
5. `MoveContinuousAbsolute` approach/sustain 交接无速度突变，`ENDVELOCITY` 按时间过渡；
6. 普通 `HYD_STOP` 按输入减速时间完成，且不受旧段参数污染；
7. 急停不受普通停止时间影响；
8. 压力目标连续修改、反向修改时 ramp 设定连续；
9. `INPRESSURE` 不在 ramp 未完成时提前成立；
10. 不可行到位时沿原方向平滑停住，`POSITIONREACHED=FALSE`，无错误报警；
11. `FB_HydAxis` 不再包含压力斜率换算和 `rPresLastCycle` 逻辑；
12. 现有接口、规划器、压力控制、停止和 IEC 合同测试全部迁移到毫秒语义。

## 9. 风险与限制

- 接口字段名保留但单位改变，旧配方数值必须重新调试；
- 没有 jerk/S 曲线时，速度连续且斜率有界，但加速度在阶段边界可能变化；
- 实际机械位置和压力响应不一定在设定时间内完成，规划器只能保证命令轨迹平滑；
- 越程结果不属于故障，调用方必须使用 `POSITIONREACHED` 或 `bPositionReached` 判断是否真正到位；
- 液压轴不自动反向修正，工艺层需决定后续修正动作。

## 10. 实施范围

本设计涉及：

- `iec/FB_HydAxis.st`；
- `src/motion_interface.c` 及其公共接口注释/结构；
- `src/motion_control.c`；
- `src/motion_planner.c/.h`；
- `src/ramp_controller.c/.h`；
- 必要的公共数据结构、校验和诊断定义；
- 相关 IEC、运动规划、停止、压力控制和集成测试。

本设计不包含 jerk/S 曲线实现、不包含自动反向修正、不包含无关的控制器调参和硬件驱动变更。

实施时不预先重写完成判定、诊断或结构体体系；只有当现有边界无法表达本设计的可观察结果时，才做局部扩展。每个实现切片通过针对性测试后再进入下一个切片，最后运行相关完整回归。若实测内存或执行时间显著增加，先缩减新增状态和计算，再考虑扩大设计范围。
