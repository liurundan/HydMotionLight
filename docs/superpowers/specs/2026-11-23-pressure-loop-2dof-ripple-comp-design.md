## 2. 证据与结论修订

### 2.1 辨识出的对象（油阀全关）

| 量 | 流量域 | 转速域（G = 20 rpm/(L/min)） | 说明 |
|---|---|---|---|
| 静态增益 R（= ksys） | 104 bar/(L/min) | 5.2 bar/rpm | 保压流量 ≈ P/104，泵内泄为主 |
| 液压刚度 Kq | 64 bar/s/(L/min)（50–100 bar），约 80（140 bar） | 3.2 / 4.0 bar/s/rpm | dP/dt = Kq·(Q − P/R) |
| 回路总延迟 | — | — | 约 5–8 ms（MA3 + 1 拍 + 伺服起步 3–5 ms） |
| 纹波 | — | — | 泵轴 12 阶，幅值 1.05–1.24 bar，与转速无关；开环相位一致（−127°…−145°），约 90% 能量锁定泵轴角 |

### 2.2 结合 50 cc/rev、1700 rpm 的修订

1. **20 rpm/(L/min) = 1000/50，相当于容积效率取 1。** 前面所有流量都是"指令理论流量"，泵内泄已经包含在 R 里，辨识结论本身不用改。
   但生产程序里如果启用 pumpConfig（容积效率 0.95），换算系数会变成 21.05，所有流量域参数随之偏移 5%。
   因此新增的对象参数**统一用转速域**（bar/rpm、bar/s/rpm），与现有 ksys 参数一致，不受换算系数影响。
2. **泵最大流量 85 L/min**，但 PressureHandle 的流量上限是 20 L/min × FLOWLIMITPERCENT。
   所以油阀全关时升压速率上限约 Kq·(20 − P/R) ≈ 1200 bar/s，受工艺上限约束，而不是泵能力。
3. **记录到的卸压流量是 −7.2 L/min**，按 −0.08 × 泵流量上限反推得 90 L/min，即 PUMP_SPEED_LIMIT = 1800 rpm。
   这对应 `iec/FB_HydAxis.st:5` 中 `rPumpMaxRPM := 1800` 的默认值，应改为 1700（卸压流量变为 −6.8 L/min）。
4. **保压转速只有 9–27 rpm（不到 1700 的 1.6%）。** 这个转速区内泄占主导，保压所需流量基本等于泄漏量。
5. **Kq ≈ β/V。** 按 64 bar/s/(L/min)、β = 1.2–1.6×10⁴ bar 推算，有效容积约 3–4 L，对应的是油阀全关时的管路容积。
   锁模、射出动作会把油缸腔容积并进来，所以：
   - Kq 会成倍下降，必须按动作逐轴标定；
   - 纹波幅值与 Kq 成正比，油阀全关是纹波最坏工况。
6. **锁模高压稳、射出保压振，这个冲突有对应的机理。**
   - 回路 L = Kp·Kq/s·(1 + 1/(Ti·s))·e^(−s·Td)。穿越频率 ωc ≈ Kp·Kq，相位裕度 PM ≈ 90° − atan(1/(ωc·Ti)) − ωc·Td。
   - 现行等效控制律 Ti ≈ 25 ms。Kq = 64 时 PM ≈ 23°。
   - Kq 减半（容积变大）时，ωc 从 3.9 Hz 降到 2.7 Hz，积分相位滞后反而变大，PM 降到约 17°，表现为振荡。
   - 这就是"只能降增益才能所有动作都稳"的原因。
   - 对策：各轴保持 ωc·Ti ≈ 4，增益随 1/Kq 缩放，即 Kp = 2π·fc/Kq，Ti = 4/(2π·fc)。
   - 这条解释尚待射出保压数据确认，射出可能还有机械谐振，见 §9。

### 2.3 现状闭环的主要缺口

1. 20 ms 时间斜坡等于阶跃，没有设定值整形。
2. 积分单步限幅 0.08 和速度阻尼组合成约 300 bar/s 的隐式限速；到位时积分里还存着约 4.7 L/min 多余流量，所以固定超调约 7 bar。
3. RBF 增益贴在窗口边界，KP 在下限、KI 在上限，等效为 Ti ≈ 25 ms 的增量 PI，PM ≈ 25°。纹波频带（3.9–4.5 Hz）正好落在灵敏度峰上，被放大 1.1–1.6 倍。
4. 没有模型前馈；现有的 targetFlow/3.5 是常值。
5. 纹波补偿存在以下问题：
   - 齿数写成 13；
   - 没有次级通道补偿；
   - 输出没有接入；
   - 层次违规。
6. **新发现：** `HYD_PressureController_InitState` 在每段开始都会 memset 整个控制器状态，`rbfInitialized` 因此被清零，RBF 每段都完全重新初始化。
   - 后果：RBF 的跨段学习保持实际上没有生效。本设计不改 RBF，只记录这个问题。
   - 本设计新增的纹波补偿系数必须避开这个陷阱，见 §4.5。

## 3. 决策

| 项 | 决策 |
|---|---|
| 结构 | 二自由度：带速率限制和制动的参考轨迹，加模型前馈，加位置式 PI 反馈（与延迟参考比较），加 N/2N 阶泵轴角同步纹波补偿 |
| 反馈 | 复用 `pressure_controller.c` 的非 RBF 分支（P/PI/PID），本轴选 PI（参数 25 = 2） |
| RBF | 代码不动，本轴不再选用 |
| 启用开关 | 新参数 Kq > 0，且所选策略不是 RBF，才走新路径；Kq = 0 时完全走旧路径 |
| 参数归属 | 轴级 WriteParameter，各动作轴（锁模、射出）各配一套；R 复用现有参数 34 ksys |
| 新参数单位 | 转速域：Kq 用 bar/s/rpm，ksys 用 bar/rpm |
| 纹波阶次 | 新参数 N（泵每转纹波次数，本机 12），补偿 N 与 2N 两阶；N = 0 关闭 |
| 内部常数 | 进 `hyd_config.h` §14B |

## 4. 设计

### 4.1 结构

```
目标压力 Pt ──► [参考轨迹：速率限制 + √制动] ──► r, ṙ
  r, ṙ ──► [模型前馈 Qff = ṙ/Kq + r/R] ──────────────────────┐
  r ──► [延迟 8 拍] ─► r_d ─► e = r_d − P ─► [PI 条件积分] ─────┤ Σ ─► 限幅/卸压策略 ─► 流量 ─► 泵转速
  泵轴角 θ、转速 n、e ──► [N/2N 阶纹波补偿，仅保压学习] ───────┘
```

- 前馈负责"按轨迹供油"。
- 反馈只修正模型误差，所以增益可以按裕度设计，不必兼顾升压速度。
- 纹波补偿只在保压时工作，不参与升压过程。

### 4.2 参考轨迹（`ramp_controller`，新增 profiled 执行函数，旧函数保留）

- **输入**：
  - 目标 Pt；
  - 过渡时间 T：沿用 PRESSURERAMPRATE（ms），语义变为"最短过渡时间"；
  - 升压速率上限 v_rise、降压速率上限 v_fall：由 §4.3 的辅助函数给出；
  - 制动时间 Tb：参数 38，0 时取 120 ms。
- **目标变化时**（含 CONTINUOUSUPDATE 在线修改），按当前方向计算：
  - v_auto = v_rise 或 v_fall；
  - v_lim = min(v_auto, |Pt − r| / T)；
  - a = v_auto / Tb。a 只取决于 v_auto，所以制动强度与用户设的 T 无关。
- **每拍（dt = 1 ms）**：
  - rem = Pt − r，s = sign(rem)；
  - v_t = s·min(v_lim, √(2·a·|rem|))；
  - 加速或反向时：v += clamp(v_t − v, ±a·dt)；减速时：v = v_t；
  - r += v·dt；越过 Pt 时令 r = Pt、v = 0。
- **输出**：r（rampedPressure）、ṙ = v（新增 rampedPressureRate）。
- **状态**：新增 rate、目标、速率上限、减速度。段起点仍由 `HYD_RampController_Init` 置为实测压力，速率置 0。

### 4.3 模型前馈与轨迹速率上限（`pressure_controller`）

- **换算**：Kq_f = Kq × G，R_f = ksys × G，其中 G = flowToPumpSpeedGain [rpm/(L/min)]。
- **前馈**：Qff = ṙ/Kq_f + r/R_f。ksys = 0 时省略泄漏项，由积分补偿。
  新路径下用 Qff 替换 `input->feedforwardFlow`，涉及跟踪积分、未饱和输出和输出记录三处。
- **速率上限**（新增辅助函数，供 motion_control 在执行轨迹前调用），η = 0.6：
  - v_rise = η·Kq_f·max(Qmax − Pt/R_f, 0.1·Qmax)，Qmax = 本段 outputMax；
  - v_fall = η·Kq_f·(|Qrev| + Pt/R_f)，Qrev = 请求的卸压下限（−0.08 × 泵流量上限）。
  - 用意：前馈本身不触限，至少留 40% 余量给反馈。
- **示例**（油阀全关，Kq = 3.0 bar/s/rpm 即 60 流量域，100 bar，Qmax 20）：
  - v_rise ≈ 686 bar/s，Tb = 120 ms 时 a ≈ 5700 bar/s²；
  - 降到 50 bar 时 v_fall ≈ 262 bar/s。
- **Kq 宁低勿高**：取工作区间内辨识到的最低 Kq 再乘 0.9。
  - 仿真：配置值比真实值高 25%，超调 2.8–3.4 bar；
  - 配置值比真实值低到一半，超调仍 ≤ 1.5 bar。见 §5.2。

### 4.4 反馈与卸压（非 RBF 分支，仅 Kq > 0 时生效的部分）

- **误差**：e = deadband(r(k−8) − P)。
  - 参考延迟 8 拍（§14B），与回路延迟匹配，避免前馈正常起效时反馈"抢油"；
  - 延迟线在段开始时用初始 r 填充。
- **PI**：沿用现有位置式 PI、条件积分抗饱和和积分限幅，不改代码。
- **增益**（各轴按公式设置）：Kp = 2π·fc/Kq_f，Ki = Kp·2π·fc/4，fc 默认 5 Hz。
  - 油阀全关（Kq_f ≈ 60–64）：Kp = 0.5 L/min/bar，Ki = 4.0 1/s（Ti ≈ 125 ms）。
  - 预计 PM ≈ 60–65°；保压纹波频率处 |S| ≤ 1，不再放大。
- **卸压**：在 `HYD_UpdateReliefState` 中加入轨迹方向判断。
  - 进入：P > 5 且（e ≤ −2 或 单拍目标降幅 ≥ 2 或 ṙ < 0）；
  - 退出：（P ≤ 5 或 e ≥ −0.5）且 ṙ ≥ 0。
  - 原因：轨迹化之后单拍降幅不会超过 1 bar，原来的"目标降幅 ≥ 2 bar"条件永远不会触发；不补这一条，多段保压降压时只能靠自然泄漏，非常慢。
  - 旧路径 ṙ ≡ 0，行为不变。

### 4.5 泵轴角同步纹波补偿（新模块 `src/pressure_ripple_comp.c` / `include/pressure_ripple_comp.h`）

- **阶次**：k₁ = N，k₂ = 2N，N 为参数 39，本机 12，0 表示关闭。
- **输入**：
  - 泵轴角 θ 和转速 n：来自已有的 `input->pumpFeedback`，要求 ANGLE 和 RPM 两个有效位都置位；
  - 误差 e（§4.4 的延迟参考误差）；
  - 参考是否在运动（ṙ ≠ 0）；
  - 上一拍输出是否触限；
  - Kq_f、R_f、Kp、Ki。
- **补偿系数**：每阶一个复系数 c_k，按"每 rpm"归一化存储。
  - 依据：保压时纹波流量幅值正比于 n（排量纹波、泄漏调制两种来源都满足），所以换压力段后可以直接沿用。
- **输出**：u = fade·n·Σ Re{c_k·e^(j·k·θ)}，每阶幅值 |c_k|·n ≤ 1.5 L/min。
- **学习律**（带次级通道逆的归一化 LMS）：
  - 次级通道 Ph(jω) = G/(1 + C·G)，其中 G = Kq_f·e^(−jω·Td)/(jω + Kq_f/R_f)，C = Kp + Ki/(jω)，Td = 6 ms，ω = k·2π·n/60；
  - 更新：c_k ← c_k + μ·dt·2·e·e^(−j·k·θ) / (Ph_k·n)，μ = 4 s⁻¹。
  - 模型延迟误差 ±5 ms 时，12/24 阶相位误差不超过 20°，仍然收敛（已仿真）。
- **门控**：
  - 学习：参考静止 ≥ 50 ms、|e| < 3 bar、n ≥ 3 rpm、反馈有效、上一拍未触限、2N·n/60 < 100 Hz，同时满足；
  - 输出：保压 50 ms 后 50 ms 内淡入；参考开始运动或反馈无效时 20 ms 内淡出。
  - 结果：升压和降压过程中纹波补偿不出力，不影响超调。
- **合成**：未饱和输出 = Qff + P + I + D + tracking + u。
  - 条件积分判断包含 u；
  - 输出触限时下一拍冻结学习，防止系数饱和积累（仿真中出现过这种发散）。
- **持久化**：
  - 系数放在 `HYD_PressureControllerState` 的子结构里；
  - `InitState`（每段开始）保存后恢复，跨段、跨模次保留；
  - `ClearState`（复位、禁用、故障）清零。
- **代价**：每拍 2 对 sin/cos、约 150 次浮点运算，无动态内存。

## 5. 仿真验证

**模型**：
- 对象：积分加泄漏。Kq 在 100 bar 以下为 64，140 bar 升到 80（流量域）；R = 104。
- 延迟：伺服纯延迟 2–6 ms；MA3；控制器看到的是上一拍压力。
- 纹波：泵侧 12/24 阶流量纹波，开环压力幅值按 1.2/0.18 bar 标定。
- 置信度：用现行控制律回放，超调与实测相差 ±1.3 bar；纹波放大倍数比实测偏高 1.2–1.6 倍，结论偏保守。
- 仿真脚本是一次性分析工具，不进仓库；仓库内的回归由 §6 T6 的 C 测试承担。

### 5.1 名义工况

伺服延迟 4 ms，配置 Kq = 64，Kp 0.49 / Ki 3.85。连续多段：0→100→140→80→120→50 bar。

| 方案 | 各段超调 bar | 各段保压 1 s 峰峰 bar |
|---|---|---|
| 新结构，不开纹波补偿（B1） | 0.86 / 0.99 / 1.13 / 0.93 / 0.78 | 2.16 / 2.50 / 1.90 / 2.35 / 1.36 |
| 新结构，开纹波补偿（B2） | 0.75 / 0.71 / 0.82 / 0.69 / 0.34 | 0.28 / 0.31 / 0.25 / 0.30 / 0.22 |

| 140 | 6.2 / 293 ms / 不能进入 | 1.17 / 290 ms / 443 ms |

### 5.2 鲁棒性

η 0.6、Tb 120 ms、参考延迟 8 拍。表中为整段序列的最大超调，单位 bar。

| 真实 Kq / 配置 Kq | 伺服 2 ms | 伺服 4 ms | 伺服 6 ms |
|---|---|---|---|
| 0.8（配置偏高） | 2.8 | 3.0 | 3.4 |
| 1.0（含 Kq 随压力上升） | 1.09 | 1.11 | 1.48 |

- 参考延迟 4→8 拍、Tb 80→120 ms，都是为了让伺服延迟到 6 ms 时仍然达标。
  代价是 t98 比激进参数（上一轮报告的 147 ms）慢 40–80 ms。
- 容积增大 4 倍（Kq = 16，增益按公式、fc = 5 Hz）：
  - 超调 ≤ 0.3 bar；保压峰峰 0.35–0.63 bar，开补偿后 ≤ 0.08 bar；
  - 0→100 的 t98 为 620 ms，受 20 L/min 工艺上限约束。

## 8. 上机调试与验收

### 8.1 逐轴标定（锁模高压、射出保压；油阀全关已有初值）

1. **ksys**：在 2–3 个压力下稳定保压，ksys = 保压压力 ÷ 保压转速（bar/rpm），取平均。
2. **Kq**：在转速基本恒定的升压段（开环转速阶跃，或闭环升压中段 30%–70%）：
   Kq = (dP/dt) ÷ (n − P/ksys)，单位 bar/s/rpm。取工作区间内最低值再乘 0.9。
3. **辅助脚本**：`scripts/identify_pressure_plant.py`（仅用标准库），读取 VOFA CSV，输出 ksys、Kq、主纹波阶次和幅值。

油阀全关的初值：ksys = 5.2，Kq = 2.9，即 3.2 × 0.9。

### 8.2 增益

- 换算系数 G = 20（若生产启用容积效率 0.95，则为 21.05）。
- 公式：Kp = 2π·fc / (Kq·G)，Ki = Kp·2π·fc / 4，fc 从 5 Hz 起。
- 若某动作出现振荡（射出保压最可能），把 fc 降到 3 Hz，Kp、Ki 按公式重新计算。

### 8.3 验收步骤

1. **B1**（参数 39 = 0），油阀全关：
   - 升压 50/80/100/120/140 bar，降压 140→80、120→50 bar；
   - 判据：超调 < 1.5 bar，t98 不慢于现状 + 60 ms；
   - 记录保压峰峰值，预期 1.4–2.5 bar。
2. **B2**（参数 39 = 12）：
   - 重复步骤 1；
   - 判据：保压 3 s 后峰峰值 < 2 bar，12 阶幅值下降 ≥ 60%，超调仍 < 1.5 bar；
   - 第二次进入同一压力时，应在 0.5 s 内达标（系数跨段保留）。
3. **锁模高压、射出保压**：
   - 按 §8.1 标定、§8.2 设增益后，在各自工作压力下复验同样的判据；
   - 先 B1 后 B2。
4. **需要记录的信号**：现有 7 列，加调试通道 0–7，射出轴再加位置和速度。

## 9. 风险与对策

| 风险 | 影响 | 对策 |
|---|---|---|
| Kq 配置偏高 | 超调 2.5–3.5 bar | 宁低勿高（× 0.9）；验收超调超标时先把 Kq 降 15% |
| 实际回路延迟 > 8 ms | 升压末段超调 | 已按伺服 6 ms 验证；超标时把 §14B 参考延迟调到 10–12 |
| 射出存在油柱加螺杆质量的谐振（模型未包含） | 保压振荡 | 降低 fc；请提供射出保压数据确认 |
| 保压低于约 15 bar（n < 3 rpm） | 纹波补偿不工作 | 低压时纹波绝对值本来就小，可接受 |
| rActPumpPosition 不是泵轴角 | 阶次对不上 | 参数 39 可配；上机前确认 |
| 降压轨迹允许反转卸压 | 改变降压动态 | T3 覆盖；上机做降压阶跃验收 |
| 容积大的动作升压慢（20 L/min 上限） | t98 变长 | 属于工艺上限，必要时提高 FLOWLIMITPERCENT 或修改 PressureHandle 的 20 L/min 基数（另议） |
