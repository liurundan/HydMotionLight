## 0. 结论速览

1. **纹波是确定性的泵排量脉动，不是随机噪声。**〔实测〕角度同步解调显示，压力波动能量 78%–100% 集中在轴转角的整数阶上，其中 13、26、39、52 阶（13 齿齿轮泵的啮合阶次族）占绝对主导；宽带随机残差仅 0.26–0.39 bar rms。传感器量化噪声 0.0012 bar rms、白噪声底 0.0075 bar rms，**比纹波小两个数量级，完全不是限制因素**。

2. **闭环压不住纹波的根本原因是环路带宽不足 + 等效延迟过大。**〔实测〕辨识出对象时间常数 τ = 0.899 s、泄漏电阻 R_h = 124.4 bar/(L/min)，反推控制器等效比例增益 Kp ≈ 0.253 (L/min)/bar，得直流环路增益 L₀ = 31.5、**穿越频率仅 5.57 Hz**。而 140 bar 工况下 26 阶纹波频率已达 9.84 Hz、52 阶达 19.7 Hz，全部落在穿越频率之上，灵敏度 |S| ≥ 0.5，实测 39/52/65/78 阶的 |S| = 0.86–2.14，**闭环在这些频段是放大而不是抑制**。反推出的等效环路延迟约 20 ms（中位数 16 ms）。

3. **现有 RBF 自适应在本机上结构性失效，系统等价于固定增益增量式 PI。**〔实测+代码〕归一化标尺 `flow_normalization_scale = fMaxFlow ≈ 90 L/min`〔代码 `src/rbf_pid.c:640`〕，而保压工作点实际输出仅 1.13 L/min，导致网络输入 x[0] ≈ 0.013，几乎贴死在第一个中心 `c[0][0]=0`〔代码 `src/rbf_pid.c:237`〕上。由此算出的 Jacobian ≈ 0.011 bar/(L/min)，**只有真值 124.4 的 1/11 000**，再乘上归一化误差后，Kp 的单步学习量约 1.3×10⁻⁸，比步长限幅 `RBF_PID_KP_STEP_LIMIT = 0.01`〔代码 `src/rbf_pid.c:39`〕小 6 个数量级。同时学习冻结死区 `RBF_PID_STEADY_DEADZONE_RATIO = 0.01 × 250 = 2.5 bar`〔代码 `src/rbf_pid.c:33`〕远大于实测稳态误差 0.4 bar，**稳态时 `is_steady` 恒为真，学习被永久冻结**。实测等效 Kp = 0.253 与初值 `PID_MIN_KP = 0.2`〔代码 `include/rbf_pid.h:45`、`src/rbf_pid.c:221`〕基本吻合，印证"几乎没学过"。

4. **积分时间被整定得过快约 20 倍，微分项实际无效，速度阻尼在稳态永不激活。**〔实测+代码〕`KI ∈ [0.005, 0.008]` 按每拍累加，等效连续积分增益 5–8 (L/min)/(bar·s)，积分时间 Ti = Kp/Ki_cont ≈ 32–50 ms，而对象 τ = 899 ms，**Ti/τ ≈ 0.04**（工程经验值应为 0.25–1.0）。`KD ∈ [0.015, 0.035]` 配二阶差分，在 100 Hz 处贡献仅为 Kp 的 6%〔实测反推〕，既不能抑制纹波也无明显噪声放大，属于"占着计算不干活"。速度阻尼门限 `RBF_PID_VEL_DAMP_RISE_THRESH = 0.31 bar/step`〔代码 `src/rbf_pid.c:58`〕，而稳态纹波造成的单步压力变化 rms 仅 0.037 bar/step，**低一个数量级，该功能在保压段完全旁路**。

5. **软限幅正在制造高压段稳态误差。**〔实测+代码〕软限幅 `cap = P_set × 1.05 / K`〔代码 `src/rbf_pid.c:152`〕。按辨识的 K = 125.8 bar/(L/min) 计算，140 bar 时 cap = 1.169 L/min，而实测维持 140 bar 所需的泄漏补偿流量已达 1.135 L/min，**裕度仅 3%**；120 bar 裕度 5.6%、100 bar 7%。这与实测稳态误差随压力单调恶化完全对应：50 bar 时 −0.002 bar、80 bar −0.004、100 bar −0.075、120 bar −0.230、140 bar **−0.405 bar**。

6. **速度反馈通道在本工况下不可用，这是被忽视的严重问题。**〔实测〕`rActRawSpeedRPM` 全程只有 17 个离散值，LSB = 14.6338 rpm（等于 1 个编码器计数 / 1 ms），而位置 LSB = 0.0878°（4100 counts/rev，12 bit）。22.7 rpm 时每毫秒只走 1.55 个计数，**速度反馈的量化误差 ±7.32 rpm 相当于真实转速的 32%**。由位置差分得到的轴速 sd 高达 8.5–10.4 rpm（占均值 45%–55%），其中绝大部分是量化台阶而非真实机械抖动。任何依赖速度反馈的观测器、阻尼或诊断在此分辨率下都不可信。

7. **要达到 140 bar / p2p ≤ 3.0 bar，单靠整定参数不够，必须同时做"角度同步前馈 + 压缩环路延迟 + 适度提带宽"。**〔实测推算〕时域重构给出的量化预期：
   - 仅整定 PID（把纹波带灵敏度 S 压到 0.05 的理想极限）→ p2p ≈ **2.42 bar**，但这是不计延迟的理论上界，20 ms 延迟下不可实现；
   - 仅做 13/26/39/52 阶角度同步前馈 → p2p 5.13 → **4.12 bar**（−19.7%）；
   - 前馈扩展到 13k（k=1…8）→ **3.22 bar**（−37.2%）；
   - 前馈 + 延迟压到 ≤2 ms + Kp 提升 2.7 倍（f_c 5.6 → 15 Hz）→ 预计 **≈3.0 bar**，刚好达标；
   - 再叠加"排量减半、泵速翻倍"→ 预计 **≈1.7 bar**，明显优于目标。
   
   结论：**3.0 bar 是软件方案的下限边界，没有余量；要稳定达标并留出裕度，必须动泵速/排量或加蓄能器。**

## 1. 数据可信度与预处理说明

三份 CSV 列结构一致：`rActPressureRaw, rActPressureFiltered, rTargetPressure, rPIDControllerOutputFlow, rTargetSpeedRPM, rActRawSpeedRPM, rActTorquePercent, rActPumpPosition`。

〔实测〕按 `rTargetSpeedRPM`（开环）/ `rTargetPressure`（闭环）的指令跳变切分工况段，开环 5 个有效段（8/10/12/15/20 rpm），闭环 5 个有效段（50/80/100/120/140 bar），各段之间均有 2–6 s 的卸压间隔，段边界清晰。

分析中做了三点必要处理，否则结论会被污染：

- **开环段必须去趋势。** 开环是堵转憋压状态，泄漏随油温上升而增大，压力并非平衡：8 rpm 段 1 s 均值从 t=3 s 的 32.6 bar 一路漂到 t=20 s 的 48.9 bar，20 s 内漂移 16.5 bar，1 阶幅值高达 3.23 bar。直接做 FFT 会让直流泄漏把低频段全部淹没。故功率谱统一先减 1000 ms 居中滑动平均，阶次分析统一按轴角重采样（对慢漂移天然免疫）。
- **稳态窗口取段后 40%–55%。** 闭环阶跃的 10%–90% 上升时间为 77–189 ms，但压力峰值出现在 0.2–2.8 s，说明存在秒级慢过程，取后段才代表真稳态。
- **阶次分析用轴角重采样 + 整数转数截断。** 取 512 点/转、2 的整数幂转数，使整数阶精确落在 FFT 谱线上，无泄漏。这是把"随转速变的脉动"和"固定频率干扰"分开的唯一可靠方法。

**必须提醒的数据缺陷：**

| 通道 | 问题 | 影响 |
|---|---|---|
| `rActRawSpeedRPM` | LSB = 14.63 rpm，仅 17 个离散值〔实测〕 | 不可用于任何速度域分析或闭环；本报告全部轴速均由 `rActPumpPosition` 差分重算 |
| `rActPumpPosition` | 12 bit（4100 counts/rev），低速下每 ms 仅 1.55 count | 轴速瞬时值量化严重，只能用长窗口平均 |
| `rActTorquePercent` | 单位标注为 %，但 140 bar 段均值 −138.76、最小 −160.5〔实测〕，**超过 100%** | 与设计文档"0.1% 额定转矩（permille）"的定义一致，即实际是千分比；若按 % 解读则电机长期超载，不合理。本报告按 permille 理解，**建议核实采集侧的量纲标注** |
| `rPIDControllerOutputFlow` | 开环段恒为 −7.2000 L/min〔实测〕 | 开环时该字段不是控制器输出，疑为记录时的固定偏置/占位，开环分析中已忽略 |
| 无独立时间戳列 | 依赖"1 ms 定周期"假设 | 与任务说明一致；若实际存在丢拍，所有频率结论按比例偏移，但阶次结论不受影响 |

## 2. 从实验数据辨识出的系统特性

### 2.1 泵与执行链

〔实测〕闭环各工况下 `rTargetSpeedRPM / rPIDControllerOutputFlow` 恒等于 **20.000 rpm/(L/min)**，五个压力点无一例外，说明流量→转速换算是纯静态线性增益，无死区、无滞环。

由此反推泵排量：
```
Q [L/min] = n [rpm] / 20   →   D = Q·1000/n = 50 mL/rev
```
〔推断〕50 mL/rev 属于中小型注塑机射胶泵的合理排量。

〔实测〕交叉验证：20 rpm 开环堵转时压力 126.1 bar，泄漏流量 = n/20 = 1.0 L/min，则泄漏系数 = 1.0/126.1 = 7.93 mL/(min·bar)；闭环 140 bar 稳态所需流量 1.135 L/min，泄漏系数 = 8.11 mL/(min·bar)。两条独立路径得到的泄漏系数一致（7.8–8.6 mL/(min·bar)），**且几乎不随压力变化 → 泄漏以层流缝隙泄漏为主，可建模为线性电阻**。

### 2.2 被控对象模型（流量域）

采用标准保压模型 `C_h·dP/dt = Q_pump − P/R_h`，即 `G(s) = P/Q = R_h/(1 + s·R_h·C_h)`：

| 参数 | 辨识值 | 辨识方法 |
|---|---|---|
| R_h（泄漏电阻） | **124.4 bar/(L/min)** | 各稳态点 P/Q_leak 平均，五点分别 115.6 / 128.9 / 128.2 / 126.2 / 123.0〔实测〕 |
| C_h（液压容度 V/βₑ） | **7.23 mL/bar** | 阶跃初始斜率 C_h = Q_peak/(dP/dt)，六次阶跃分别 9.80 / 6.78 / 6.39 / 6.93 / 6.65 / 6.82〔实测〕 |
| τ = R_h·C_h | **0.899 s（899 ms）** | 上两项相乘 |
| 对象极点 | 0.177 Hz | 1/(2πτ) |
| dP/dt 上限 | ≈ 790 bar/s | 阶跃前 60 ms 平均，Q_peak ≈ 5.3 L/min〔实测〕 |

〔推断〕C_h = V/βₑ = 7.23 mL/bar。若取含气油液的有效体积模量 βₑ ≈ 700 bar（工程常见值，纯油 1400–1700 bar），则等效受压容积 V ≈ 5 L；若 βₑ = 1400 bar 则 V ≈ 10 L。**这个值偏大，提示管路较长或存在软管/蓄能腔，也可能是油液含气量偏高**——后者对纹波极其不利（βₑ 降低直接放大 |Z|）。建议实测确认。

### 2.3 阶跃响应品质

〔实测〕六次压力阶跃：

| 阶跃 | 上升时间(10–90%) | 超调 | 峰值时刻 | n_cmd 峰值 |
|---|---|---|---|---|
| 0 → 50 bar | 77 ms | 3.18% | 0.207 s | 133.6 rpm |
| 0.9 → 80 bar | 108 ms | 2.57% | 0.447 s | 107.8 rpm |
| 2.2 → 100 bar | 129 ms | 2.62% | 0.274 s | 100.9 rpm |
| 0.3 → 120 bar | 156 ms | 2.28% | 1.156 s | 109.3 rpm |
| 0.5 → 140 bar | 189 ms | 2.18% | 2.279 s | 106.1 rpm |
| 0.7 → 50 bar | 82 ms | 2.53% | 2.769 s | 107.9 rpm |

评价：**瞬态品质本身是合格的**（超调 2.2–3.2% 优于验收要求的 5%〔代码 `docs/rbfpid-calibration-acceptance.md:18-23`〕），但存在两个隐患：

- 上升时间随目标压力线性变长（77 → 189 ms），因为升压所需流量受软限幅与流量上限约束，压力越高、可用裕度越小。
- **峰值时刻从 0.2 s 一路推迟到 2.8 s**，说明阶跃后存在秒级二次爬升。结合开环段的慢漂移特征，〔推断〕这是油温/泄漏变化引起的慢过程，加上积分时间过短（Ti ≈ 39 ms）导致的低频积分过冲。这部分不是纹波问题，但会让"稳态"定义变模糊。

### 2.4 执行器负担：转速指令抖动已达失控量级

〔实测〕闭环稳态段转速指令统计：

| P_set | n_cmd 均值 | n_cmd sd | n_cmd p2p | **p2p/均值** | 反向占比 |
|---|---|---|---|---|---|
| 50 bar | 8.65 rpm | 1.73 | 10.65 | **123%** | 0% |
| 80 bar | 12.41 | 2.57 | 18.96 | **153%** | 0% |
| 100 bar | 15.59 | 3.49 | 26.63 | **171%** | 0.08% |
| 120 bar | 18.99 | 4.51 | 33.02 | **168%** | 0% |
| 140 bar | 22.70 | 5.51 | 39.41 | **174%** | 0.06% |

这是本报告最需要正视的一组数字：**稳态保压时，转速指令的峰峰摆动是平均转速的 1.7 倍**，140 bar 时在 −1.88 ~ 37.52 rpm 之间来回甩。对应流量指令在 −0.094 ~ 1.876 L/min 摆动，而维持压力只需 1.135 L/min。

后果：
- 电机反复加减速，转矩 p2p 达 50.1%（140 bar），机械冲击与发热显著；
- 出现反向转速指令（−1.88 rpm），在保压段意味着瞬时反向流量，有吸空/气蚀风险；
- **这么大的执行器动作，换来的纹波抑制却几乎为零**（26 阶以上 |S| ≈ 1）——能量全部浪费在与延迟赛跑上。

〔实测〕按阶次分解 n_cmd：140 bar 时 26 阶分量幅值 4.04 rpm、13 阶 2.48 rpm、52 阶 2.35 rpm。而要真正抵消泵排量脉动，所需转速调制量仅为 Δn = n_mean × 排量脉动率：13 阶约 1.2 rpm、26 阶约 0.64 rpm。**控制器实际注入的 26 阶转速调制是所需的 6.3 倍，且相位偏离理想负反馈点约 36°**——它不是在补偿泵脉动，而是在徒劳地追逐 20 ms 前的压力信号。

## 3. 压力噪声类型判别

把稳态压力波动按物理来源分解为四类，逐一给出实测证据：

### 3.1 传感器量化噪声与电子白噪声 —— **可忽略**

〔实测〕五个闭环工况一致：

| 项目 | 数值 |
|---|---|
| 压力原始值 LSB | 0.00400 bar |
| 量化噪声（LSB/√12） | 0.00115 bar rms，占信号 0.13%–0.36% |
| 200–500 Hz 白噪声底（raw） | 0.0264–0.0293 bar rms |
| 200–500 Hz 白噪声底（filtered） | 0.0072–0.0081 bar rms |
| 与压力水平的相关性 | 无（50 bar 与 140 bar 的噪声底相同）→ 属加性噪声，不随工作压力放大 |

结论：**噪声底 0.008 bar rms 对应 p2p 约 0.03 bar，而实测纹波 p2p 是 2.2–6.9 bar，相差 200 倍。传感器分辨率与噪声完全不是当前瓶颈**，不需要为降噪而牺牲带宽。

### 3.2 现有压力滤波器的实际效果 —— **在纹波频段等于没有滤波**

〔实测〕`rActPressureFiltered` 与 `rActPressureRaw` 的分频对比（140 bar 段）：

| 频带 | filt/raw 幅值比 |
|---|---|
| 0.5–5 Hz | **1.000** |
| 5–20 Hz | **0.998** |
| 20–50 Hz | 0.987 |
| 50–150 Hz | 0.958 |
| 150–300 Hz | 0.479 |
| 300–500 Hz | 0.211 |

全工况总方差削减仅 0.09%–2.15%。这说明现有滤波器的一阶截止频率在 **150 Hz 以上**，而全部纹波能量在 3–40 Hz〔实测：3–10 Hz 占 30%–45%，10–30 Hz 占 39%–49%〕。

〔代码〕这与实现一致：`src/pressure_controller.c:622-624` 明确将 `filteredPressure = input->measuredPressure` 直接透传，注释写"传感器层已滤波，不再叠加以免增加 1 ms 环相位滞后"；`filterAlpha` 解析函数恒返回 1.0〔`src/pressure_controller.c:119-123`〕。只有压力速率做了一阶低通（`derivativeFilterAlpha = 0.05`）。

**判断：滤波器的设计意图（避免相位滞后）是对的，但现状是"纹波一点没滤、相位一点没省"。真正需要的是一个在 3–40 Hz 有针对性衰减、同时相位代价可控的滤波器，而不是一个 150 Hz 的高频抗混叠滤波器。**

### 3.3 确定性周期脉动 —— **主因，占能量 78%–100%**

见第 4 节详述。

### 3.4 慢漂移（热/泄漏） —— **开环下极大，闭环下已被积分消除**

〔实测〕分解结果对比：

| 工况 | 1000 ms 滑动平均后的趋势 p2p | 去趋势后的高频 p2p |
|---|---|---|
| 开环 8 rpm | 16.47 bar | 4.84 bar |
| 开环 15 rpm | 18.73 bar | 7.04 bar |
| 开环 20 rpm | 16.67 bar | 7.82 bar |
| 闭环 100 bar | **0.218 bar** | 4.60 bar |
| 闭环 140 bar | **0.247 bar** | 6.90 bar |

结论：**闭环积分把慢漂移压到 0.25 bar 以内，这部分工作得很好，不需要动**。开环那 16–19 bar 的漂移纯粹是堵转状态下泄漏随油温变化的自然结果，不是控制缺陷，但它意味着**任何基于开环数据辨识的稳态参数都必须去趋势**，否则会得出完全错误的泄漏系数。

同时提示一个真实工程风险：闭环 140 bar 时趋势 p2p 仍有 0.247 bar、sd 0.049 bar，且软限幅裕度只有 3%（见 0.5 条）。**油温继续升高 → 泄漏继续增大 → 所需补偿流量超过软限幅 → 压力将无法维持**。这在长时间保压或高温车间会变成"压力缓慢掉下去"的现场故障，建议提前处理。

## 4. 周期流量脉动的特征描述

### 4.1 主阶次族 = 13 齿齿轮泵啮合阶次

〔实测〕开环五工况的角度同步解调结果（压力幅值，单位 bar）：

| 泵速 | 轴频 | 13 阶幅值 | 13 阶频率 | 26 阶幅值 | 39 阶 | 52 阶 |
|---|---|---|---|---|---|---|
| 7.96 rpm | 0.133 Hz | 0.723 | 1.725 Hz | 0.362 | 0.237 | 0.276 |
| 9.98 rpm | 0.166 Hz | 0.982 | 2.161 Hz | 0.569 | 0.203 | 0.271 |
| 12.00 rpm | 0.200 Hz | 0.987 | 2.599 Hz | 0.653 | 0.215 | 0.284 |
| 14.99 rpm | 0.250 Hz | 1.069 | 3.247 Hz | 0.924 | 0.240 | 0.308 |
| 19.97 rpm | 0.333 Hz | 1.106 | 4.325 Hz | 1.093 | 0.195 | 0.320 |

三条硬证据锁定"13 齿齿轮泵"：

1. **主峰频率严格正比于转速，比例系数 = 13。** 8 rpm 段主峰 1.709 Hz，13×8/60 = 1.733 Hz（轴速实测 7.963 rpm → 1.725 Hz）；10 rpm 段主峰 2.197 Hz vs 计算 2.161 Hz；12 rpm 段 2.686 Hz vs 2.599 Hz；15 rpm 段 3.174 Hz vs 3.247 Hz。**频率随转速线性移动，排除任何固定频率的电气或结构干扰。**
2. **谐波严格按 13 的整数倍排列**：13、26、39、52、65、78、91、104 阶全部检出，闭环 140 bar 段 13 的倍数共 16 个阶次幅值 > 0.05 bar。
3. **转矩的 13 阶分量远大于压力响应**：140 bar 时转矩 13 阶幅值 7.38%，压力仅 0.374 bar，T/P = 19.7 %/bar，而平均 T/P 仅 0.99 %/bar，**放大 19.9 倍**。这说明 13 阶是"泵排量脉动直接产生大转矩波动"的源侧扰动，而不是负载压力波动引起的被动响应。

〔推断〕13 齿外啮合齿轮泵的流量脉动率理论值约 5%–8%（峰峰 15%–25%）。实测 13 阶转矩幅值/平均转矩 = 4.8%–5.3%，与理论吻合，**属该泵型的正常水平，不是泵损坏或磨损异常**。

### 4.2 关键特征：幅值随转速/压力的增长规律

〔实测〕

- **13 阶幅值随转速增长但趋于饱和**：0.723 → 1.106 bar（转速 ×2.5，幅值 ×1.53）。归一化 A13/n 从 0.0908 降到 0.0554 bar/rpm，说明不是简单的"流量脉动 ∝ 转速"。〔推断〕低速时 |Z| 大（容性阻抗 1/(2πf·C)，f 低则 |Z| 大），高速时 |Z| 下降部分抵消了流量脉动的增大，两者叠加得到弱增长。
- **26 阶幅值近似正比于转速**：0.362 → 1.093 bar（转速 ×2.5，幅值 ×3.0），A26/n 基本恒定在 0.045–0.062。〔推断〕26 阶是啮合二次谐波+困油效应，其流量脉动幅值本身随转速线性增长，而该频段 |Z| 已开始下降但不足以抵消。
- **26 阶在高速下反超 13 阶成为最大分量**：20 rpm 开环时 A26 = 1.093 > A13 = 1.106（几乎相等）；闭环 140 bar 时 A26 = 0.605 显著大于 A13 = 0.374。**这是因为闭环对 13 阶（4.92 Hz，接近 f_c=5.57 Hz）还有 0.34 的抑制能力，而对 26 阶（9.84 Hz，已超 f_c）只剩 0.56，抑制能力断崖式下降。**
- 39、52 阶幅值基本不随工况变化（0.20–0.28 / 0.27–0.32 bar），是相对固定的小分量。

### 4.3 第二阶次族：12 / 24 / 72 阶

〔实测〕除 13 的倍数外，还稳定存在 12、24、48、72、120 阶族，其中 24 阶压力幅值 0.179–0.304 bar、72 阶 0.256–0.269 bar，**72 阶在 80 bar 段幅值 0.259 bar，是该工况第二大分量，超过 13 阶的 0.151 bar**。

溯源判据〔实测〕：

| 阶次 | 压力幅值 | 转矩幅值 | n_cmd 幅值 | T/P | n_cmd/P |
|---|---|---|---|---|---|
| 13（140 bar） | 0.374 | 7.38 | 2.48 | **19.7** | 6.63 |
| 24（140 bar） | 0.304 | 1.50 | 1.51 | 4.92 | 4.97 |
| 26（140 bar） | 0.605 | 3.84 | 4.04 | 6.36 | 6.68 |
| 72（140 bar） | 0.256 | 1.91 | 1.08 | 7.45 | 4.22 |

13 阶的 T/P 高达 19.7，明显区别于其他阶次的 4–7，再次印证 13 阶是"源侧排量脉动"。而 24/72 阶的 T/P 与 n_cmd/P 都与相邻的 26/52 阶接近，**说明它们与闭环响应耦合在一起，不是独立的强扰动源**。

〔推断〕24 = 12×2、72 = 12×6，12 阶族的来源有两种可能，需进一步核实：
- **电机转矩脉动**：永磁同步电机的 6 次电气谐波转矩脉动（逆变器死区 + 反电动势谐波），若极对数为 2 则对应 12 阶机械、极对数 4 对应 24 阶。这与"驱电一体机把纹波做得很小"的对比高度相关——一体机的电流环带宽和死区补偿通常远优于分体方案。
- **机械传动**：联轴器/花键的 12 齿结构，或泵轴-电机轴连接件的周期性刚度变化。

〔未获取〕现有数据不含电机电流、极对数、联轴器参数，无法定论。**建议补做一次"电机空载脱开泵、同转速旋转"的测试**：若 12/24/72 阶依然存在则为电机侧，消失则为泵/传动侧。这是成本最低的判别实验。

### 4.4 脉动的时域形态

〔实测〕用整数阶重构时域波形，140 bar 段重构 p2p = 5.13 bar，占实测 p2p（6.88 bar）的 79.2%，重构 rms 占 95.5%。残差 0.26 bar rms 落在 **分数阶**（12.5、13.5、25.5、38.5 阶），即"阶次 ± 0.5"。

〔推断〕分数阶边带的物理含义是**轴速本身在波动**（转速抖动会让严格的整数阶产生边带）。但需警惕：由 12 bit 位置差分得到的瞬时轴速 sd 高达 10.4 rpm（占均值 46%），其中大部分是量化台阶。**在速度反馈分辨率改善之前，无法区分"真实转速抖动产生的边带"和"编码器量化产生的伪边带"**。这一项标注为待验证。

## 5. 闭环抑制能力的定量刻画：灵敏度函数

这是理解"为什么闭环反而压不住"的核心。定义扰动灵敏度 `S(jω) = P_closed / P_open`（同一轴速下，闭环残余纹波幅值 / 开环原始纹波幅值）。S < 1 表示抑制，S > 1 表示**闭环放大了扰动**。

〔实测〕用开环五工况按轴速线性插值得到 A_open，与闭环实测 A_closed 相除：

| P_set | 13 阶 | 26 阶 | 39 阶 | 52 阶 | 65 阶 | 78 阶 | 91 阶 |
|---|---|---|---|---|---|---|---|
| 80 bar | **0.152** | **0.404** | 0.858 | 0.858 | 1.368 | 1.569 | 1.635 |
| 100 bar | **0.257** | **0.498** | 0.967 | 1.085 | 1.360 | 1.642 | 1.613 |
| 120 bar | **0.421** | **0.559** | 1.176 | 1.309 | 1.692 | 2.137 | 2.005 |
| 140 bar | 0.340* | 0.570* | 1.400* | 1.546* | — | — | — |

\* 140 bar 的轴速 22.7 rpm 超出开环标定范围（8–20 rpm），按 A13/n、A26/n 归一化外推，可信度低于其他行。

**规律极其清晰：**

- 13 阶（2.7–4.9 Hz）：S = 0.15–0.42，**有效抑制，最好 6.6 倍**；
- 26 阶（5.4–9.8 Hz）：S = 0.40–0.57，抑制能力减半；
- 39 阶（8.1–14.8 Hz）：S ≈ 0.86–1.40，**抑制能力丧失**；
- 52 阶及以上（10.7 Hz+）：S = 0.86–2.14，**闭环在放大扰动，最坏 2.14 倍**。

且 **S 随工作压力升高而系统性恶化**（13 阶：0.152 → 0.257 → 0.421）。〔推断〕原因有两个，都指向同一个方向：
1. 压力升高 → 泵速升高 → 纹波频率升高 → 更远离穿越频率；
2. 压力升高 → 软限幅裕度收窄（3%–7%）→ 控制器可用增益下降。

### 5.1 与理论模型的对齐验证

用辨识参数计算理论灵敏度并与实测对比（模型：`L(jω) = Kp·R_h/(1+jωτ)`，`S = 1/|1+L|`）：

| 工况/阶次 | f (Hz) | 实测 S | 无延迟模型 S | 含延迟模型 S | 拟合延迟 |
|---|---|---|---|---|---|
| 80 bar / 13 | 2.685 | 0.152 | 0.424 | 0.424 | 0 ms |
| 100 bar / 13 | 3.378 | 0.257 | 0.507 | 0.507 | 0 ms |
| 120 bar / 13 | 4.096 | 0.421 | 0.581 | 0.581 | 0 ms |
| 80 bar / 26 | 5.370 | 0.404 | 0.683 | 0.683 | 0 ms |
| 120 bar / 52 | 16.385 | 1.309 | 0.944 | 1.304 | 22 ms |
| 120 bar / 78 | 24.578 | 2.137 | 0.974 | 1.293 | 51 ms |
| 100 bar / 91 | 23.647 | 1.613 | 0.972 | 1.308 | 53 ms |

〔实测〕**无延迟模型在 13/26 阶（低频段）与实测偏差较大（模型偏保守），但在 39 阶以上必须引入延迟才能解释 S > 1。全部 f > 4 Hz 数据点拟合出的等效环路延迟均值 20.4 ms、中位数 16 ms。**

物理解释：低频段（< f_c）实测 S 比无延迟模型更好，是因为积分作用（Ti ≈ 39 ms，积分转角频率 4.1 Hz）在低频提供了额外增益；高频段 S > 1 且必须靠延迟解释，是典型的**延迟导致的相位裕度耗尽 + 灵敏度峰值（waterbed 效应）**。

### 5.2 相位证据

〔实测〕n_cmd 相对 P 的相位（理想负反馈应为 180°）：

| 工况 | 13 阶 | 26 阶 | 39 阶 | 52 阶 | 78 阶 |
|---|---|---|---|---|---|
| 80 bar | −116.9° | −140.0° | −141.0° | −150.8° | −147.9° |
| 100 bar | −111.1° | −145.0° | −140.0° | −150.9° | −145.3° |
| 120 bar | −98.7° | −147.8° | −126.5° | −146.7° | −139.7° |
| 140 bar | **−70.6°** | −143.9° | −126.4° | −144.3° | −140.9° |

**140 bar 的 13 阶相位已到 −70.6°，距离理想负反馈点 180° 相差 109°，已超过 90° —— 该阶次上控制器已进入正反馈区**。这与 26 阶以上普遍停留在 −140° ~ −150°（距 180° 仅 30–40°，裕度极小）共同说明：**环路相位裕度已被延迟吃干，任何提升增益的尝试都会立刻引发振荡**。

## 6. 波动根源的分层归因

按"贡献度 × 可改动性"排序，每一层都给出实测依据。

### 第 1 层：扰动源 —— 13 齿外啮合齿轮泵的固有排量脉动（贡献 ~60%）

- 〔实测〕开环 20 rpm 时 13 阶 1.106 bar、26 阶 1.093 bar、39 阶 0.195 bar、52 阶 0.320 bar，**开环 p2p 达 21.2 bar**。这是"无任何控制干预"时的真实扰动水平。
- 〔实测〕转矩 13 阶放大倍数 19.9 倍于均值，确认是泵侧排量脉动而非负载扰动。
- 〔推断〕外啮合齿轮泵的困油现象与齿间容积变化是物理必然，13 齿是脉动与成本的折中。**这一层不改硬件就无法根除，只能补偿。**

### 第 2 层：对象阻抗 —— 液压容度过小，纹波频段阻抗偏高（贡献 ~20%）

- 〔实测〕C_h = 7.23 mL/bar。纹波频段（10 Hz）的对象阻抗 |Z| = R_h/√(1+(2πfτ)²) = 124.4/√(1+(62.8×0.899)²) = 2.22 bar/(L/min)。
- 〔推断〕同样幅值的流量脉动，|Z| 越大压力波动越大。**增大 C_h（加蓄能器）能按 1/C 比例直接降低纹波**，这是最"物理"的手段。但代价是 τ 同比增大、带宽同比下降，需权衡。
- 〔推断〕C_h 偏小的另一个可能是油液含气（βₑ 从 1400 掉到 700 bar 就让 C_h 减半）。**油液脱气/检查吸油侧密封是零成本的第一步**。

### 第 3 层：环路带宽不足 + 等效延迟 20 ms（贡献 ~15%，但是**最关键的杠杆**）

- 〔实测〕f_c = 5.57 Hz，而 26 阶纹波在 140 bar 时已达 9.84 Hz，**纹波主频段整体位于穿越频率之上**，闭环从原理上就无能为力。
- 〔实测〕隐含等效延迟 16–20 ms。按 1 ms 控制周期计，这相当于 16–20 拍。
- 〔推断〕延迟构成分解（**需现场实测确认，以下为工程典型值**）：采样保持 0.5 ms + 传感器内部滤波（未知，若为 150 Hz 一阶则 1.1 ms）+ 现场总线往返 2–8 ms + 伺服速度环响应 2–5 ms + 泵-管路-传感器传输 1–3 ms + 控制器计算与输出更新 1–2 ms。
- **这一层是软件侧最大的机会点**：延迟每减半，可支撑的带宽约翻倍，S 在纹波频段可下降 3–5 倍。

### 第 4 层：控制器参数与实现缺陷（贡献 ~5%，但**修复成本最低**）

## 7. 为什么汇川驱电一体机能把纹波压到 3.0 bar 以内

> 说明：以下基于公开资料的技术宣称 + 工程原理推断。〔未获取〕我没有汇川内部实现资料，也没有其在你这台机器上的同工况实测数据，因此这是机理解释而非对标实测。

### 7.1 公开可查的指标

- 汇川注塑机伺服驱动器公开资料宣称：**压力波动范围小于 ±0.5 bar**、"0 → 最大压力"响应时间最短 20 ms、支持 CANbus 多泵合流（最高 16 泵）、通过压力传感器实时调节伺服电机转速或转矩实现流量与压力精准控制。
- 其子公司伊士通（EST，汇川控股）主营"精密液压伺服控制系统"，与汇川合计市场占有率在行业前列。
- 行业常用的低脉动泵（如住友 QT 系列内啮合齿轮泵）公开标称**压力脉动约 0.2 MPa（= 2 bar）**，且"特殊齿形消除大部分困油冲击，压力、转速升高时噪音变化很小"。

### 7.2 机理层面的六个差异（按重要性排序）

**① 环路延迟量级不同 —— 这是最根本的差异**

一体机把压力环放进驱动器内部，与电流环（62.5–125 μs）、速度环（250 μs–1 ms）同芯片运行，压力反馈直接进 ADC，输出直接进 SVPWM。**环路延迟可做到 0.5–2 ms。**
你当前的架构是：外部控制器 1 ms 任务 → 现场总线 → 伺服驱动器速度环 → 编码器 → 总线返回 → 下一拍使用，实测等效延迟 16–20 ms。

后果的定量差别：假设同样要求相位裕度 45°，
- 延迟 1.5 ms → 可支撑穿越频率约 80–100 Hz；
- 延迟 20 ms → 可支撑穿越频率约 6–8 Hz。

**带宽差 12 倍，直接决定了 26 阶（9.84 Hz）能不能被抑制。** 你现在的 f_c = 5.57 Hz，26 阶刚好在边界外；一体机的 f_c 若为 80 Hz，26 阶的 S 可以做到 0.05 以下。这是数量级差别，不是调参能弥补的。

**② 低脉动泵型**

〔推断〕一体机方案通常配内啮合齿轮泵（QT 系列等），公开标称压力脉动约 2 bar；而你用的是 13 齿**外啮合**泵，开环 20 rpm 时实测 p2p 21.2 bar、13 阶幅值 1.106 bar。**泵型差异可能就是 5–10 倍的源侧差距**，这一项与控制器无关。

**③ 高得多的泵工作转速**

一体机方案通常泵速在 200–1500 rpm 区间，而你的保压工况泵速只有 **8–23 rpm**。这带来三重后果：
- 纹波频率：1500 rpm × 13 / 60 = 325 Hz，远超压力环关心范围，且被管路/容度自然衰减；23 rpm × 13 / 60 = 4.9 Hz，正好落在环路最敏感的频段。
- 速度反馈分辨率：1500 rpm 下每 ms 走 102 个计数，量化误差 0.5%；23 rpm 下每 ms 走 1.55 个计数，量化误差 32%。
- 泵本身效率与稳定性：外啮合泵在 < 30 rpm 时容积效率急剧下降、齿面润滑不良，脉动率反而增大。

〔推断〕**23 rpm 的保压转速本身就是一个"困难工况"**，很可能是为了极致节能而牺牲了控制性能。这是最值得优先审视的系统级选择（见 8.5）。

**④ 低速段改用转矩控制而非速度控制**

〔推断〕成熟方案在低速保压段会切换到转矩模式（或压力-转矩复合），因为低速速度环受分辨率与摩擦限制性能差。你的数据里 `rActTorquePercent` 的 13 阶幅值高达 7.38%，说明转矩信号本身携带了极强的泵脉动信息，**用它做前馈或做内环，比用被量化到 ±7.32 rpm 的速度反馈可靠得多**。

**⑤ 电流环带宽与死区补偿**

〔推断〕一体机的电流环带宽通常 1–2 kHz，且有完善的逆变器死区补偿。这会显著压低 6 次电气谐波转矩脉动——正好对应你在数据里看到的 12/24/72 阶族。

**⑥ 参数整定是按整机做的，不是按算法做的**

〔推断〕量产方案的 Kp/Ki 是针对"该泵 + 该电机 + 该管路"离线整定后固化的配方，并且按工艺段（注射/保压/熔胶）分别调度。你的 RBF 自适应本意是免整定，但如第 6 节 4.1/4.2 所述它实际没在工作，所以你现在跑的是一组**从未针对本机整定过的窗口下限默认值**（Kp=0.2, Ki=0.005, Kd=0.015〔代码 `src/rbf_pid.c:221-223`〕）。

## 8. 优化方案（按优先级与投入产出排序）

### 8.0 总体策略

**必须先做的判断：3.0 bar 是"软件方案的极限边界"，不是"软件方案能轻松达到的目标"。**

〔实测推算〕把纹波带灵敏度压到理想的 S = 0.05，重构 p2p 仍有 2.42 bar；把 13k 全部阶次前馈抵消干净，重构 p2p 3.22 bar。两条路各自的极限都在 2.4–3.2 bar 之间，**留给工程裕度的空间几乎为零**。因此推荐路线是：

> **P0 修缺陷（零成本，先让自适应真正工作）→ P1 压延迟+重整定（软件，目标 4.0 bar）→ P2 角度同步前馈（软件，目标 3.0 bar）→ P3 硬件/工况（决定能否留出裕度，目标 ≤2.0 bar）**

### 8.1 P0：修复实现缺陷（不改控制结构，1–2 天，先做）

这一层的意义是：**你现在的 RBF-PID 实际上没有自适应，跑的是默认 PI。在修好之前，任何"调 RBF 参数"的尝试都是在调一组不生效的数字。**

**P0-1 修复归一化标尺，让 Jacobian 回到正确量级**

〔代码〕`src/rbf_pid.c:640`：
```c
pid->flow_normalization_scale = (pid->fMaxFlow > 0.0f) ? pid->fMaxFlow : 90.0f;
```
问题：`fMaxFlow = pumpSpeedLimit / flowToPumpSpeedGain`〔`src/pressure_controller.c:343`〕，若 `pumpSpeedLimit = 1800 rpm` 则为 90 L/min，而保压工作点仅 1.13 L/min，x[0] = 0.013，落在中心网格 `c[i][0] = 0.2i`〔`:237`〕的最边缘，导数几乎为零且符号不稳。

建议（三选一，推荐 B）：
- **A. 按工艺段设置流量标尺**：保压段传 `flow_normalization_scale = 3.0 L/min`（约工作流量的 2.6 倍），使 x[0] ≈ 0.38，落在 `c[1][0]=0.2` 与 `c[2][0]=0.4` 之间，激励充分。改动最小，但需上层按段下发。
- **B. 让标尺跟随工作点自适应**（推荐）：用慢速一阶跟踪 `u_scale = max(2·|u_slow|, 0.5 L/min)`，其中 `u_slow` 是输出流量的 1 s 时间常数低通。这样任何工艺段都自动居中，且不需要上层配合。需注意标尺变化时同步重置网络或按标尺比例缩放权重，避免语义漂移。
- **C. 改中心网格**：`c[i][0]` 改为对数分布 `{0.005, 0.01, 0.02, 0.05, 0.1, 0.3}`。改动侵入性大，不推荐。

同时把 Jacobian 钳位上限从 50 提到 300〔`src/rbf_pid.c:375`〕——辨识出的真实 K = 124.4 bar/(L/min)，当前上限 50 会把正确结果削顶。

**P0-2 修复学习冻结门限**

〔代码〕`src/rbf_pid.c:33`：
```c
static const float RBF_PID_STEADY_DEADZONE_RATIO = 0.01f;   /* RBF冻结死区 = 0.5%*量程 */
```
注释写 0.5%、代码是 1%，且 1% × 250 bar = 2.5 bar，远大于验收要求的稳态误差 1 bar〔`docs/rbfpid-calibration-acceptance.md:22`〕，逻辑上**自相矛盾：只要误差满足验收标准，学习就必然被冻结**。

建议：
```c
/* 冻结门限应显著小于目标稳态精度，且按设定值而非满量程归一 */
static const float RBF_PID_STEADY_DEADZONE_RATIO = 0.0004f;  /* 0.1 bar @250bar 量程 */
static const float RBF_PID_STEADY_DEADZONE_MIN   = 0.05f;    /* 下限 0.05 bar */
```
并把死区改为 `max(RATIO * pressure_scale, 0.02 * |P_set|)`，避免低压段死区相对过大。同时修正注释与代码的不一致。

**P0-3 激活速度阻尼（稳态纹波阻尼）**

〔代码〕`src/rbf_pid.c:58`：`RBF_PID_VEL_DAMP_RISE_THRESH = 0.31f`（bar/step）。实测稳态单步压力变化 rms 仅 0.037 bar/step，**门限高 8.4 倍，功能在保压段完全旁路**。

建议：门限降到 **0.02 bar/step**，增益从 0.15 降到 **0.05–0.08 L/min/(bar/step)** 后重新标定，限幅从 1.0 降到 **0.15 L/min**（稳态流量才 1.13 L/min，1.0 的限幅等于没限）。

另外，当前实现只在压力上升方向生效〔`:571-575`〕，会造成不对称阻尼（上升被压、下降放任），在正弦纹波上等效于引入偶次谐波失真。建议改为**双向对称**，仅在卸压/溢流阶段整体旁路（用工艺段状态而非压力变化符号判断）。

**P0-4 放宽软限幅，消除高压段稳态误差**

〔代码〕`src/rbf_pid.c:30`：`RBF_PID_SOFT_CAP_RATIO = 1.05f`。

实测 140 bar 时 cap = 1.169 L/min vs 实际需求 1.135 L/min，裕度 3%，直接造成 −0.405 bar 稳态误差。建议：
- 比值提到 **1.25**（cap = 1.39 L/min，裕度 22%）；
- 更好的做法是**按泄漏模型计算 cap**：`cap = P_set/R_h_measured × 1.2 + margin`，其中 `R_h_measured` 由稳态 P/Q 在线辨识（已有 `K`/`systemGainBarPerRpm` 通道〔`src/pressure_controller.c:484-486`〕可复用）；
- 同时增加"接近软限幅"的诊断告警，因为这是油温过高/内泄加剧的早期信号。

**P0-5 学习率需要重新标定**

〔代码〕`include/rbf_pid.h:55-60`：w/c/b/p/i/d 学习率全部 ≈ 5.0。这是在 Jacobian 失效（≈0.011）的前提下"看起来还能用"的值。一旦 P0-1 修好、Jacobian 回到 124 量级，**梯度会放大约 11 000 倍，5.0 的学习率必然导致参数发散**。

建议：修 P0-1 的同时把学习率降到 **eta_w/eta_c/eta_b = 0.002–0.02**、**eta_p/eta_i/eta_d = 0.0001–0.001**，参考仓库已有的 conservative 组合〔`tests/test_rbf_pid_pressure_benchmark.c:63-77`：`etaW=0.002, etaP=0.0001`〕，再逐步上调。**这两项必须同批改，不能只改一项。**

### 8.2 P1：压缩环路延迟 + 重构控制器（1–2 周，核心杠杆）

**P1-1 先测量延迟预算，不要猜**

这是所有后续工作的基础。建议做一次专项测试：在控制器输出处叠加一个已知的 13 阶正弦转速调制（幅值 0.5 rpm，绕过 PID），同时记录 `rActPumpPosition`、`rActPressureRaw`、`rActTorquePercent`，用角度同步解调直接读出"注入相位 → 压力响应相位"的差值，即为**除控制器外的全部延迟**。然后逐项排查：

| 环节 | 排查方法 | 典型可优化量 |
|---|---|---|
| 现场总线 | 换用更高同步精度的传输周期/DC 同步；确认是否每拍都收发 | 2–6 ms |
| 伺服速度环 | 提高速度环带宽；确认驱动器内部滤波时间常数 | 1–3 ms |
| 压力传感器滤波 | 向供应商索取实际截止频率；若 >100 Hz 可换更快的 | 0.5–2 ms |
| 控制器输出时序 | 确认"本拍采样 → 本拍输出"还是"本拍采样 → 下拍输出" | 1 ms |
| 采样保持 | 无法消除 | 0.5 ms |

〔实测推算〕目标：把等效延迟从 16–20 ms 压到 **≤3 ms**。仅此一项就能把可支撑穿越频率从 5.6 Hz 提到 30 Hz 以上。

**P1-2 按已批准的设计迁移到位置式 RBF-PI + 显式积分状态 + 反算抗饱和**

〔代码〕当前是增量式〔`src/rbf_pid.c:554-558, 584`〕：
```c
du = KP*(error - e_prev1) + clamp(KI*error, ±0.08) - KD*d_term;
Output = u_prev + du + f_velfb + ff_delta;
```
三个结构性问题（设计文档 §2.3 已明确指出〔`docs/superpowers/specs/2026-08-06-pressure-ripple-suppression-design.md:65-99`〕）：
1. `u_prev` 同时充当"上一拍输出"、"隐式积分累积"、"无扰切换状态"三重身份，在最终 RPM 限幅器动作后无法正确反算 → **抗饱和失效**；
2. `KI*error` 是每拍累加，未按 `sampling_period` 归一，Ki 的物理单位不明确；
3. 已知的前馈/阻尼项叠加在 `Output` 上而非进入积分状态，会被积分"学回去"。

建议按 spec §6.2 的公式实现：
```c
e_control = P_set - P_filtered;
p_term    = Kp * (beta * P_set - P_filtered);          /* beta<1 降低设定值踢 */
i_cand    = i_state + Ki * Ts * e_control;             /* Ki 单位 (L/min)/(bar·s) */
u_rate    = clamp(-Krate * LPF(dP_filtered/dt), ±u_rate_max);
u_raw     = u_ff + p_term + i_cand + u_rate;
u_base    = flow_limit_and_slew(u_raw);

n_base    = FlowToRPM(u_base);
n_command = limit_rpm_slew(n_base + delta_n_ripple);   /* 前馈在 RPM 域叠加 */
u_applied = RPMToFlow(n_command - delta_n_ripple);     /* 反算时剔除已知前馈 */
i_state   = i_cand + Kaw * Ts * (u_applied - u_raw);   /* 反算抗饱和 */
```
关键点是 **`i_state` 显式存在、单位是 L/min、并且在反算前先剔除角度同步前馈**，这样积分器不会把周期性补偿吸收掉。

**P1-3 重新整定 PID（在延迟压下来之后）**

以辨识参数 τ = 0.899 s、R_h = 124.4 bar/(L/min)、Kp 单位 (L/min)/bar 为基础：

| 参数 | 现值 | 建议值（延迟 ≤3 ms 后） | 依据 |
|---|---|---|---|
| Kp | 0.2–0.5 窗口，实测生效 0.253 | **0.6–0.9** | f_c = Kp·R_h/(2πτ)，Kp=0.68 → f_c = 15 Hz |
| Ti = Kp/Ki_cont | ≈ 39 ms | **225–450 ms**（τ/4 ~ τ/2） | Ti/τ 从 0.04 提到 0.25–0.5 |
| Ki（连续，(L/min)/(bar·s)） | 5–8 | **1.5–3.0** | Ki_cont = Kp/Ti |
| KI（每拍，若保留增量式） | 0.005–0.008 | **0.0015–0.003** | KI = Ki_cont × Ts |
| Kd | 0.015–0.035 | **0（禁用）** | 实测贡献仅 6%，且二阶差分对 13 阶纹波敏感 |
| 测量速率阻尼 Krate | 0.15（门限 0.31 未激活） | **0.05–0.08**，门限 0.02，双向 | 替代 Kd 提供阻尼，物理意义明确 |

〔实测推算〕Kp 从 0.253 提到 0.68（×2.7）的效果：f_c 5.57 → 15 Hz，则
- 13 阶（4.92 Hz）：S 从 0.34 → ≈0.10
- 26 阶（9.84 Hz）：S 从 0.57 → ≈0.22
- 52 阶（19.7 Hz）：S 从 1.31 → ≈0.55

**前提是延迟已压到 ≤3 ms**。若延迟仍是 20 ms，Kp×2.7 会在 5.6 Hz 附近触发灵敏度峰值，13 阶（相位已到 −70.6°）立刻进入正反馈而振荡。**这一条是硬约束，不能跳过 P1-1 直接提增益。**

**P1-4 增加针对纹波频段的反馈滤波（与 P1-3 配套）**

〔实测〕现有滤波在 3–40 Hz 的衰减是 0.998–0.987，等于没有。建议增加一个**二阶低通、截止 30–40 Hz**的反馈专用滤波器：
- 30 Hz 二阶 Butterworth 在 9.84 Hz（26 阶）衰减 0.90、相位滞后 33°；在 19.7 Hz（52 阶）衰减 0.55、滞后 76°。
- 相位代价必须计入延迟预算，因此**截止频率不能低于 30 Hz**，否则会吃掉 P1-1 换来的带宽。
- 若延迟已压到 2 ms，可放宽到 25 Hz 截止换取更强的 52 阶衰减。

不要用提高滤波强度代替前馈——滤波只能衰减，无法消除，且必然付出相位代价。

### 8.3 P2：角度同步谐波前馈（2–3 周，达标的关键）

〔代码〕设计已批准〔`docs/superpowers/specs/2026-08-06-pressure-ripple-suppression-design.md:276-302`〕，`HYD_PumpFeedback.angleDeg` 字段已存在〔`include/common_types.h:33`〕，但 `src/` 下无任何实现，且 `motion_control.c` 尚未消费该反馈。**这是"接口已备好、只差实现"的状态，投入产出比最高。**

**P2-1 相位跟踪器**（严格按 spec §5，不要假设角度单调递增）
```c
dtheta = angle_deg(k) - angle_deg(k-1);
if (dtheta >  180.0f) dtheta -= 360.0f;
if (dtheta < -180.0f) dtheta += 360.0f;
tooth_phase = wrap_2pi(tooth_phase + 13.0f * dtheta * 2.0f * PI / 360.0f);
```
有效性门控（spec §5 已列全）：时间戳单调、角度增量不超过按 `pumpSpeedLimit` 推出的物理上限、角度方向与转速符号一致。**角度无效时只关闭前馈，不影响基础压力环。**

**P2-2 前馈律**
```c
delta_n_ripple = A13(|n|) * sin(tooth_phase + phi13(|n|))
               + A26(|n|) * sin(2*tooth_phase + phi26(|n|));
```
按 |n| 查表，A 单位 rpm，phi 单位与文档一致（建议统一用弧度并注明）。**符号必须由标定确定，不能硬编码为减号**（spec §7 已强调）。

**P2-3 标定表 —— 本次数据已可直接生成初值**

〔实测〕用开环数据的转矩 13/26 阶幅值除以平均转矩，得到泵排量脉动率，再乘以平均转速得到所需转速调制量：

| 泵速 | 13 阶排量脉动率 | Δn13 需求 | 26 阶排量脉动率 | Δn26 需求 |
|---|---|---|---|---|
| 7.96 rpm | 3.56% | 0.28 rpm | 1.92% | 0.15 rpm |
| 9.98 rpm | 3.21% | 0.32 rpm | 2.05% | 0.20 rpm |
| 12.00 rpm | 3.47% | 0.42 rpm | 2.03% | 0.24 rpm |
| 14.99 rpm | 3.89% | 0.58 rpm | 2.41% | 0.36 rpm |
| 19.97 rpm | ~3.9%* | 0.78 rpm* | ~2.4%* | 0.48 rpm* |

\* 20 rpm 段数值按趋势外推，标定前需重新解调确认。

相位初值的正确求法：**前馈相位取决于次级路径（转速指令 → 泵轴 → 压力传感器）在该阶次频率上的相位，而不是闭环里 n_cmd 与 P 的相位差。** 实测 `phase(n_cmd − P)` 是"环路整体响应"的相位（含控制器与反馈路径），不能直接当作次级路径相位使用。

实测值仅供定性参考：26 阶 `phase(n_cmd − P) = −144°`（等价 +216° = 180° + 36°），13 阶在 140 bar 时为 −70.6°（等价 +289° = 180° + 109°），说明环路在这些频率上已累积了 36°–109° 的额外相移，主要来自等效延迟与积分项。

**必须用 P2-3 的下述标定流程现场测定次级路径相位**，不要拿这些数字直接填表：

```
1) 关闭压力闭环的反馈修正（或将 Kp、Ki 临时置零，仅保留泄漏补偿前馈）；
2) 在转速指令上注入单一阶次的正弦：n = n_mean + A_test·sin(tooth_phase + φ_test)
   （A_test 取 0.3–0.5 rpm，避免扰动过大）；
3) 对压力做同阶次角度同步解调，得到 P 的同阶次幅值 A_P 与相位 φ_P；
4) 次级路径相位 φ_sec = φ_P − φ_test，幅值增益 G_sec = A_P / A_test [bar/rpm]；
5) 前馈表填 A_k = Δn_k（由 8.3 排量脉动率算出），φ_k = −φ_sec + 180°
   （符号约定必须写入文档，并与代码中的 sin/cos 形式一致）；
6) 逐阶扫描 φ_k 在 ±40° 范围内找压力残差最小点，作为最终标定值。
```

同时记录 G_sec，它也是 P1-1 延迟预算的直接测量结果（φ_sec 随频率的斜率即群延迟）。


〔实测预期〕仅抵消 13+26+39+52 阶，重构 p2p 从 5.13 → 4.12 bar（−19.7%）；抵消 13k（k=1…8）→ 3.22 bar（−37.2%）。

**P2-4 学习门控：`e_learning` 必须用阶次清洗后的残差**

〔代码〕spec §6.4 已要求〔`:259-274`〕，当前实现直接用 `error` 驱动 RBF 学习〔`src/rbf_pid.c:402, 487-492`〕。若不改，**RBF 会把前馈注入的周期分量当成"未建模动态"学回去，与前馈对打**。实现方式：用角度同步 Goertzel 提取 13/26 阶分量，从学习误差中减除，只用残差更新权重。

**P2-5 关于在线自适应谐波抵消（FxLMS）**

spec §7 已明确把它列为后续计划，我同意这个排序。**先用固定标定表**，理由：
- 固定表确定性强、可离线验证、无发散风险，符合 STM32H7 的实时约束；
- 在线 FxLMS 需要准确的次级路径模型，而次级路径恰恰包含那个尚未测清的 20 ms 延迟——**在 P1-1 完成前做 FxLMS 等于在未知相位上闭环，发散风险很高**；
- 固定表的缺点是油温/磨损会漂移。缓解办法：**按工艺段标定多组表 + 用转矩 13 阶幅值做健康度监测**（本次数据显示转矩 13 阶幅值随工况变化明显，是天然的漂移指标）。

### 8.4 P2+：把 RBF 用在它真正擅长的地方

〔推断〕修好 P0-1/P0-2 后，RBF 的价值不在"抑制周期纹波"（那是前馈的活），而在**跟踪慢变工况**：油温变化导致的 R_h 漂移（开环数据显示 20 s 内泄漏变化足以让压力漂 16 bar）、不同模次/不同材料的负载差异、泵磨损。

具体建议：
- RBF 只调度 **Kp 与 Ki**（spec §6.4 已如此规定），不直接输出控制量；
- 网络输入改为**有物理意义的慢变量**：`[u_slow/u_scale, P/P_scale, T_q/T_scale]`（转矩是很好的工况指示器，实测 mean|T|/P 稳定在 0.99–1.18 %/bar，是可用的健康度特征）；
- 学习速率降采样到每 4–10 拍一次（spec §6.4 已建议），控制输出仍每 1 ms；
- **把 K（`systemGainBarPerRpm × flowToPumpSpeedGain`）改为在线辨识并写入**，而不是当固定常数。当前它只被用来算软限幅〔`src/rbf_pid.c:148-153`〕，spec §2.3 第 5 条已指出"它不是标定过的逆模型前馈增益，不得当作前馈使用"——这个警告是对的，但反过来它**应该**被用于软限幅的精确计算（见 P0-4）。

### 8.5 P3：硬件与工况层（决定能否留出裕度）

按投入产出排序：

**P3-1 提高保压泵速 / 减小排量 —— 效果最大且成本可控**

〔实测推算〕保持平均流量不变（即换小排量泵或改传动比），把泵速提高 N 倍：

| N | 泵速 | f13 | f26 | 13 阶幅值相对值 | 26 阶幅值相对值 | 估算 p2p |
|---|---|---|---|---|---|---|
| 1（现状） | 22.7 rpm | 4.93 Hz | 9.85 Hz | 1.000 | 1.000 | 2.77 bar |
| 2 | 45.5 rpm | 9.85 Hz | 19.70 Hz | 0.500 | 0.500 | **1.68 bar** |
| 4 | 90.9 rpm | 19.70 Hz | 39.40 Hz | 0.250 | 0.250 | **1.27 bar** |
| 8 | 181.9 rpm | 39.40 Hz | 78.80 Hz | 0.125 | 0.125 | 1.14 bar |
| 16 | 363.7 rpm | 78.80 Hz | 157.60 Hz | 0.063 | 0.063 | 1.11 bar |

机理：纹波频段 |Z(f)| ≈ 1/(2πf·C_h)，f 翻倍则 |Z| 减半，而流量脉动幅值基本不变（同排量泵同转速下的相对脉动率恒定），故压力脉动 ∝ 1/f。**N=2 就能让 p2p 从 2.77 降到 1.68 bar，N=4 降到 1.27 bar，之后受宽带残差限制而饱和。**

额外收益：泵速提高后速度反馈量化误差占比从 32% 降到 16%（N=2）或 8%（N=4），第 5 层问题同步缓解。

代价：能耗。当前 8–23 rpm 的超低速保压显然是为节能设计的，提速会增加搅油损失与电机铁损。**建议做能效对比测试后决策**；折中方案是只在"压力精度关键段"（如 V/P 切换后的保压首段）提速，其余时间回落。

**P3-2 蓄能器（保压段投入，注射段隔离）**

〔推断+计算〕纹波频段 |Z| ≈ 1/(2πf·C)，要把 26 阶开环幅值从 1.09 bar 降到 0.30 bar 需 C 提升 3.6 倍，即 C_add = 2.6 × 7.23 = 18.8 mL/bar。取绝热指数 n=1.4、工作压力 14 MPa，所需气体体积 V_gas = C·n·P = 3.7 L；考虑预充 70 bar 时 140 bar 下气体被压缩到约一半，**需标称容积 7–10 L 的皮囊式蓄能器**。

代价：τ 从 0.899 s 增到 3.2 s，f_c 同比例下降，动态响应变差。因此**必须用阀切换，只在保压段投入**。这在注塑机上是成熟做法。

**P3-3 换低脉动泵型**

〔推断〕内啮合齿轮泵（QT 系列等）公开标称压力脉动约 2 bar，而你的外啮合 13 齿泵开环 p2p 21.2 bar。若源侧能降 5–10 倍，其余所有措施的压力都会大幅减轻。这是**最彻底但改造量最大**的方案。

**P3-4 改善速度反馈分辨率**

〔实测〕当前 12 bit 位置 → 速度 LSB 14.63 rpm，在 23 rpm 工况下完全不可用。选项：
- 用驱动器内部的高分辨率速度观测器输出替代外部差分（若驱动器支持）；
- 改用更高分辨率编码器（17–23 bit）；
- 在控制器侧对位置做长窗口最小二乘拟合求速度（窗口 20–50 ms），可把有效分辨率提高一个数量级，代价是 10–25 ms 相位滞后——**与 P1-1 的目标冲突，仅在无法改硬件时作为诊断用途，不建议进控制回路**。

**P3-5 油液与管路检查（零成本，先做）**

〔推断〕C_h = 7.23 mL/bar 偏小。检查项：
- 油液含气量（吸油侧密封、回油口是否淹没、油箱液位）——含气 1% 就能让 βₑ 从 1400 掉到 700 bar；
- 软管长度与内径（软管会显著降低等效 βₑ）；
- 压力传感器安装位置是否远离泵出口（靠近泵口会直接看到全幅值脉动，远离则被管路容度自然衰减）；
- 吸油滤是否堵塞（低速下吸油阻力增大 → 气蚀 → 脉动加剧，这可能是低速工况脉动率偏高的原因之一）。

### 9.2 验证方法（每一步都要可量化验收）

**离线验证（用现有数据即可，无需上机）**
1. 把本次辨识的 τ=0.899 s、R_h=124.4、C_h=7.23、D=50 mL/rev 写入 `src/sim/PressureModel.c` 的物理模型，替换当前"固定 60 ms 一阶电机模型 + 正弦纹波"〔spec §2.3 第 7 条已指出该模型不足〕；

3. 在标定好的模型上做控制器 HIL 回归，验收按 `docs/rbfpid-calibration-acceptance.md`：上升时间 ≤800 ms、超调 ≤5%、稳态滤波压力 p2p ≤1 bar、绝对稳态误差 ≤1 bar。

**上机验证（每个阶段一次，同一工况同一窗口）**
1. 固定测试脚本：目标压力 50/80/100/120/140 bar，每段 ≥10 s，段间卸压 ≥3 s，油温稳定在 40±2 °C 后开始；
2. 采样：1 ms，**必须包含 `rActPumpPosition`**（否则无法做阶次分析，这是本次分析能成立的关键通道）；
3. 报告指标（与本报告同口径，便于横向对比）：
   - 稳态 p2p / rms / 稳态误差（后 5 s 窗口）；
   - 角度同步解调的 13/26/39/52 阶幅值与相位；
   - 开闭环灵敏度 S(f)（需配对做同泵速开环段）；
   - n_cmd p2p / 均值（执行器负担，当前 174%，目标降到 <60%）；
   - 转矩 13 阶幅值（泵健康度基线）；
   - 隐含等效延迟（由 S(f) 高频段反推，当前 16–20 ms，目标 ≤3 ms）；
4. 每项改动单独验证，**不要一次改多项**——尤其是 P0-1 与 P0-5 必须同批改但需与其他项分开测。
